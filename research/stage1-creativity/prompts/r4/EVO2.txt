 Parent B: MECHANISM: The state is an aggregate of discovered items on a graph of candidate items. Random walkers launched from unexplored territory step between neighbors until they touch the aggregate and attach, adding one item and exposing new frontier. Growth concentrates at tips that screen the most unexplored territory, since walkers reach them first, so the aggregate branches fractally over the reachable space. PAIR 2
 Parent A: MECHANISM: Knowledge is stored as thousands of small, separately trained local models. Each one is valid only on an overlapping region of context space (a "patch"), and learned restriction maps say how neighbouring patches must agree where they overlap. Inference searches for a global section: an assignment that satisfies all active patches at once, found by iterative consistency propagation instead of a single forward pass. Learning adds, splits or refits patches only where the measured disagreement (the obstruction to gluing them together) is high, and leaves every other patch untouched.
   DIFFERENCE: It can pinpoint and report exactly where its own knowledge contradicts itself, and it can learn new facts without overwriting old ones because no globally shared weights exist to interfere.
   nearest published work: sheaf neural nets / local-to-global computation (Bosca & Ghrist 2026), LWPR
 Parent B: MECHANISM: Signals are a conserved quantity routed between units. Each unit holds the flow-weighted mix of its inflows, and each decision injects a unique tracer vector that mixes along conservatively. When an outcome arrives, the local tracer composition is unmixed by solving a small mass-balance system, giving each past decision's exact share. Each link then scales its routing fraction by (1 + rate × outcome × credited tracer it carried), and nodes renormalize.
   DIFFERENCE: Exact credit across arbitrarily long delays in one forward pass, with no backward sweep or decaying trace.
   nearest published work: GFlowNet flow-conservation credit, RTRL / forward-mode sensitivities

PAIR 3
 Parent A: MECHANISM: The state is a set of proto-concepts, clusters of past examples each with a member count n. Each example joins its nearest cluster or seeds a new one, and every cluster loses members at a rate that rises as it shrinks. The example's surprise, meaning how badly existing clusters predicted it, sets a supersaturation S; a cluster reaching a critical size n*, which falls steeply as S rises, freezes into a stable concept, while smaller clusters dissolve.
   DIFFERENCE: A single highly surprising example can fix a concept, while unsurprising noise fades rather than accumulating, so the data needed is set by surprise rather than by a fixed learning rate.
   nearest published work: SUSTAIN, latent-cause models, ART vigilance
 Parent B: MECHANISM: Each raw input gets a small integer exponent vector over k hidden base dimensions. The exponents are chosen by discrete search (smallest k first) for the assignment under which data from all scales collapse onto one surface in dimensionless products. That surface is stored as a sparse table, filled in and interpolated from experience; only quantities with identical exponent vectors may be added or compared.
   DIFFERENCE: Predictions stay valid at magnitudes never seen, because the relation is built to be unchanged when any discovered dimension is rescaled.
   nearest published work: BuckiNet (Bakarji 2022), AI Feynman
