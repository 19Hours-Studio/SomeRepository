# Этап 1 — самоанализ креативности модели

Читать по порядку:
1. `00-self-analysis-preregistration.md` — гипотезы и все предсказания, записанные ДО запусков.
2. `01-round1-observations.md` — наблюдения раунда 1 (записаны до оценок судьи).
3. `02-final-report.md` — **итоговый отчёт**: находки, карточка самопредсказаний, протокол, мост к этапу 2.

Данные:
- `prompts/` (раунд 1), `prompts/r2/`, `prompts/r3/`, `prompts/opus/` — точные промпты; `prompts/r2/draws.json` — случайные выборки.
- `raw/`, `raw/r2/`, `raw/r3/`, `raw/opus/` — сырые ответы субагентов.
- `blind_set*.txt`, `blind_key*.json`, `judge_r*.md`, `judge_r*_by_condition.json` — слепые оценки и их расшифровка.
- `attractor_scores.json` — лексическая метрика (показала, что слова ≠ идеи).

Скрипты: `harvest.py` (пул слов из системных файлов), `build_prompts*.py` (промпты; случайность из `secrets`),
`extract.py` (ответ из транскрипта), `score.py` (кластеры/слепой набор), `map_judge.py` (расшифровка по тексту, который
судья реально прочитал), `blind_r2.py`, `blind_r3.py`, `check_lock.py` (машинная проверка ограничения LOCK).
