# Этап 1 — самоанализ креативности модели

Читать по порядку:
1. `00-self-analysis-preregistration.md` — гипотезы и все предсказания, записанные ДО запусков.
2. `01-round1-observations.md` — наблюдения раунда 1 (записаны до оценок судьи).
3. `02-final-report.md` — итоговый отчёт части 1: находки, карточка самопредсказаний, протокол, мост к этапу 2.
6. `05-self-improvement.md` — **самоулучшение**: движок придумывает улучшения себя, A/B v1 против v2 (v2 не лучше; почему).
5. `04-final-test.md` — **финальный тест движка** (`engine/`): движок против best-of-N на новом вопросе.
4. `03-deep-analysis.md` — **часть 2**: полная аналитика 63 идей, «где спотыкались» (14 пунктов), честная диффузия, эволюция, два судьи, литературные проверки, протокол v2 и финалисты.
7. `06-engine-v17.md` — движок v1.6–v1.8: межпрогонный анализ, ядро вопроса, гениальность, слои A→B→C (идея пользователя).
8. `07-v18-full-run.md` — полный прогон v1.8 на вопросе вне ИИ (хранение энергии), сверка намерения, пре-регистрация,
   своя проверка на порядок величины (`energy_fermi.py`) и слой D «счёт» (v1.9).
9. `08-reality-engine.md` — движок v3: идеи проверяет реальность (обучение моделей), два полигона, агент-исследователь.
10. `09-permafrost-run.md` — полный прогон конвейера по умолчанию на задаче пользователя (ресурсы под мерзлотой):
    движок против 8 обычных прогонов, починка исследователем, литература, итоговые идеи с расчётами.
11. `10-genius-engine.md` — движок v3.0: свобода в воображении, правда в отборе (тест на смерть для каждой идеи),
    новизна в сырье (фронтир доказанных возможностей и бухгалтерия ценности).
12. `11-what-is-missing.md` — разбор перед v4: ядро сейчас, счёт всех экспериментов, законы, поправка цели
    (работоспособность, а не уникальность) и чего не хватает движку (сборщик цепочек, полигон с известным ответом,
    дешёвая правда, бухгалтерия даровой работы, память между прогонами).
13. `12-calc-kit.md` — v3.4: набор проверенных расчётов и каталог классов убийц для теста на смерть.
14. `13-chain-composer.md` — v3.5: сборщик цепочек из выживших кусков; выигрыш всей цепочки после слепого аудита.
15. `14-dodecahedron.md` — v3.6: движок на загадке (римский додекаэдр): реестр фактов, прежние объяснения, слепой аудит против фактов.
    Итоговая идея коротко: `14a-dodecahedron-answer.md`.

Данные:
- `prompts/` (раунд 1), `prompts/r2/`, `prompts/r3/`, `prompts/opus/` — точные промпты; `prompts/r2/draws.json` — случайные выборки.
- `raw/`, `raw/r2/`, `raw/r3/`, `raw/opus/` — сырые ответы субагентов.
- `blind_set*.txt`, `blind_key*.json`, `judge_r*.md`, `judge_r*_by_condition.json` — слепые оценки и их расшифровка.
- `attractor_scores.json` — лексическая метрика (показала, что слова ≠ идеи).

Скрипты: `harvest.py` (пул слов из системных файлов), `build_prompts*.py` (промпты; случайность из `secrets`),
`extract.py` (ответ из транскрипта), `score.py` (кластеры/слепой набор), `map_judge.py` (расшифровка по тексту, который
судья реально прочитал), `blind_r2.py`, `blind_r3.py`, `check_lock.py` (машинная проверка ограничения LOCK).

Часть 2 (раунд 4): `analytics.py`/`analytics.json` (единая аналитика), `lit_check_finalists.md`, `lit_check_r4.md` (поиск по литературе),
`diffuse.py` + `diffusion/` (принудительная диффузия), `build_evo.py` + `prompts/r4/` + `raw/r4/` (эволюция и контроль),
`blind_r4.py`, `score_r4.py`, `judge_r4_A.md`, `judge_r4_B.md`, `judge_r4_summary.json` (два слепых судьи).
