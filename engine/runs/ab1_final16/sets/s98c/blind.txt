F01
MECHANISM: Concepts sit in a rooted tree with property characters at the leaves. The system computes the parsimony consistency index of each subtree. When convergent properties push the index below 0.6, it prunes that subtree and regrafts it where the total tree length is smallest. Inheritance inference only runs over the repaired tree.
VALUE: Properties inferred down the hierarchy stay valid, and the system restructures its own categories when inheritance fails.

F02
MECHANISM: Swap tests on logged operation sequences split the system into commuting threads. Each thread publishes its own salted hash of its quantized beliefs before evidence arrives. After the reveal, a verifier flags any thread whose beliefs moved on evidence routed to a different thread, then re-runs commutation tests on that pair. If the pair does not commute, the threads are fused and the shift is legitimized. If it does commute, the shift is penalized as rationalization. The module map and the honesty training thus revise each other. First test: Give an RNN agent two independent gridworld rooms plus one coupled pair, and run swap tests with commit-reveal belief hashes. Success: the verifier recovers the true coupling graph (F1 ≥0.9) and flags injected cross-module belief leaks with ≥90% recall.
VALUE: Third parties can verify that evidence about one part of the world changed only the beliefs it should have, and the system's modular decomposition becomes auditable and self-correcting.

F03
MECHANISM: The system tracks how its emitted claims come back to it through user prompts and documents. For refuted claims it estimates R_t in each embedding region. If R_t > 1, the region is sealed for generation-interval × log(R_t), and it may answer only from fresh external sources.
VALUE: The system can contain errors that spread through its users before they turn into consensus it has fed back to itself.

F04
MECHANISM: A new fact first goes into a queue. At each stage it is checked against a different, separate subset of the roughly 64 ensemble members, and only after other facts have been absorbed in between. Agreement between those members gives the fact's binding margin, and a fact rejected at any stage is gone for good. The number of stages grows with how much of the model the update would change. Facts that pass more stages get smaller observation noise, so the update counts them more. First test: Stream 1,000 factual updates (half correct, half deliberately false with broad downstream reach) from zsRE into a 64-member LoRA ensemble with staged disjoint-subset gating; success is ≥80% false-fact rejection at ≥90% true-fact acceptance, beating single-stage ensemble voting on neighborhood accuracy.
VALUE: The system can keep learning from a stream of new facts, and wrong facts that would cause broad damage are stopped before they get in.

F05
MECHANISM: Each internal unit's discretized activation states are treated as alleles, and pairs of co-occurring contexts are treated as diploid genotypes. A running Hardy–Weinberg test compares how often mixed ("heterozygous") pairs actually occur with how often they would occur in one homogeneous population. A significant heterozygote deficit is the Wahlund signature that the unit merges hidden subpopulations. In that case the unit is split into typed children, and the F-statistics between those children decide the routing. Children that later come back into equilibrium with each other are merged again.
VALUE: The model breaks apart conflated concepts while it runs, using an online statistical test instead of an analysis done after the fact.

F06
MECHANISM: For each concept, the system repeatedly searches for the smallest set of examples that teaches the concept to a freshly initialized small student network up to a set accuracy. The size of this set, the concept's teaching dimension, is stored as the measure of understanding. Concepts with large or unstable teaching sets are marked shallow and are rebuilt or split until a compact teaching set exists. First test: For 20 MNIST or synthetic concepts labeled by the model, greedily search minimal teaching sets that bring fresh small MLPs to 90% accuracy across seeds. Success: teaching-set size and its seed variance correlate (Spearman ≥0.6) with the model's held-out concept error and with human-rated difficulty.
VALUE: Gives the system an operational, self-checkable sense of what it really understands, and lets it explain any concept to a human or another agent through a few well-chosen examples.

F07
MECHANISM: Every layer is an exact bijection, built from coupling flows that carry an explicit "residual" latent that keeps all discarded information, so any computation can be run backward without loss. To answer "what must have been true for X to happen?", the system fixes the output and samples the residual latent while running backward. This gives the full set of inputs that are exactly consistent with X. Because the mapping can be reversed, the system can also take one training example's contribution back out of the weights by applying its inverse update exactly. Approximate fine-tuning is not needed for this.
VALUE: Exact abduction and exact, provable unlearning and provenance, which a forward-only network that discards information cannot provide.

F08
MECHANISM: The system maintains a population of small probabilistic programs, each a candidate simulator of some part of the environment. Queries are answered by running or intervening on the best-scoring simulators. Prediction errors drive program-synthesis mutations, and simulators are selected by how well they compress observations and predict accurately.
VALUE: It gives explicit causal and counterfactual reasoning and lets the system discover new models that can be inspected.

F09
MECHANISM: The system keeps a growing pool of candidate input transformations, built by composing primitive edits: relabel, permute, reflect, rescale, swap roles. At inference it answers both the original input and several transformed copies, maps each answer back through the inverse transformation, and measures how much the answers disagree. A transformation's score rises when answers agree on cases that were verified correct, and it falls when they diverge. High-scoring transformations are kept and used both to vote at inference and to enlarge the training data. Low scorers are discarded, and recombinations of kept ones are proposed as new candidates.
VALUE: The system finds on its own which changes to an input must not change the answer, which gives it structured generalization far outside its training distribution.

F10
MECHANISM: Learned transformations (analogies, translations, coordinate maps) are composed around closed cycles, and each cycle's misclosure is recorded the way a surveyor records a traverse error. A Hodge decomposition of these residuals over the cycle complex leads to three repairs. The gradient part goes back into local map corrections. The curl part localizes and deletes or rewires the specific inconsistent edges. The harmonic part shows a real topological hole, and it creates a new context variable that divides the domain into separate charts with explicit transition maps.
VALUE: The system can find out that its knowledge needs several context-dependent frames, and build them, instead of averaging contradictory regularities into one incoherent map.

F11
MECHANISM: Hidden states are trained to lie on codewords of a learned algebraic error-correcting code that has redundant parity components. At every layer the system computes the syndrome, a check value that is nonzero when the state is not a valid codeword. A nonzero syndrome locates the corrupted components, which are corrected by decoding before computation continues. Syndrome statistics are logged per layer and per topic to learn where errors originate. First test: Train a small transformer on a synthetic fact-recall task with hidden states constrained to a learned code, inject activation corruptions and use known-confabulation prompts. Success: syndrome decoding restores ≥50% of corruption-induced errors, and syndrome magnitude predicts confabulations at AUROC ≥0.8.
VALUE: Lets the system detect and repair its own internal errors, such as confabulated facts or drifting chains of reasoning, during computation, before they reach the output.

F12
MECHANISM: When a behavior fails, the system creates small parameter lesions that reproduce the failure. Pairs of lesions are "crossed" by mixing activations from the two lesioned copies. If the mix restores the behavior, the lesions sit in different functional units. If it doesn't, they sit in the same one. The groups found this way define module boundaries, and parameters are re-partitioned and re-routed to match. A map of the groups is stored and updated as new failures appear. First test: On a small transformer trained with planted, block-sparse modules for four synthetic subtasks, generate failure-reproducing lesions, cross pairs via activation mixing, and cluster; success is adjusted Rand index ≥0.7 against planted modules, exceeding activation-correlation clustering.
VALUE: The module structure comes from functional evidence, not from a design chosen in advance, so fixes, transfer and growth stay local to the unit that is actually responsible.

F13
MECHANISM: Premises and rule links are treated as redundant meters that fit one weighted least-squares situation estimate. For each premise, the system computes a residual against the others, normalized by its residual covariance. If the largest is above 3, that premise is re-typed as suspect, or a rule link's applies/doesn't-apply status is flipped, and the estimate is recomputed until every residual passes.
VALUE: A single corrupt input can no longer quietly distort the whole conclusion, because redundancy finds it and isolates it.

F14
MECHANISM: Each candidate reasoning step gets a "binding margin": how strongly it is re-derived when the context is re-encoded in a different way. The step then passes n sequential stages, and at each stage the context decorrelates further (paraphrase, dropout, abstraction). The chance of being discarded rises as the margin falls, and a discarded step cannot be restored. Only steps that survive all n stages are committed, so the error rate falls roughly as ε^n. The system adapts n, the compute it spends, to how much downstream work depends on the step.
VALUE: Long chains can be made as reliable as needed, with an explicit dial between speed and accuracy, instead of errors compounding.

F15
MECHANISM: Each state change described in the input or produced during reasoning is written as a transfer: one amount debited from one holder and credited to another, across a learned set of conserved quantities (objects, money, people, information). After every step, the totals for each quantity are summed, and they must balance. A nonzero imbalance is the training signal. If the imbalance persists, the system creates a new hidden holder to absorb it and keeps that holder only if it later balances other transfers. Quantities whose totals never actually stay constant get demoted from the conserved set.
VALUE: The system can track the state of the world exactly over very long sequences, and it can infer unmentioned participants or leaks from bookkeeping gaps.

F16
MECHANISM: For a given query, the system runs several retrieval or generation passes that are deliberately independent, each using different cues, sources or decompositions. It records which candidate facts or solutions each pass "captures". From the overlaps it computes Chao or Lincoln-Petersen estimates of how many relevant items are still missing, adjusting for the fact that some items are easier to capture than others. It keeps sampling until the estimated unseen share falls below a set threshold, and its answer states how complete it is.
VALUE: The system can say "I have probably found 90% of the relevant cases" and know when to stop searching.

F17
MECHANISM: For pairs of cues that compete over an internal feature, the system measures dose-response shifts, meaning how much more of cue A is needed as cue B increases, and fits a Schild slope. A slope of 1 confirms that one mechanism mediates both cues. If the slope differs from 1, the feature is split into two sites, each with its own learned gate. The slopes are stored per feature, and they are re-tested whenever new competing cues show up. First test: In a toy model with planted features (some single-mechanism, some secretly two superposed mechanisms), titrate competing cue pairs and fit Schild slopes on feature activation; success is ≥85% correct single-versus-composite classification (single-mechanism slopes within 0.9–1.1) and better causal-ablation faithfulness after splitting.
VALUE: Features that are secretly several mechanisms get found and separated by a quantitative invariant, so the model's internals become more faithful and reasoning that combines cues becomes more reliable.

F18
MECHANISM: Every internal quantity carries, alongside its real-valued vector, a short integer vector of exponents over a learned set of base "kinds" (like length, time, count, agent). When two quantities are multiplied or divided, their exponent vectors add or subtract. When they are added or compared, the exponents must match, and any mismatch produces an imbalance residual. That residual is the learning signal. Persistent mismatches over many examples cause a new base kind or a conversion constant to be created, and kinds that never constrain anything are merged away.
VALUE: Reasoning steps that make no physical or logical sense get rejected because their kinds don't match, and the system can extrapolate to unseen magnitudes by scaling rules instead of memorized examples.

F19
MECHANISM: Each module stores a compact functional signature: its input-output behavior on a probe set. When the gradient from new data conflicts with that signature beyond a threshold, the module is duplicated rather than overwritten. Both copies then receive complementary sparse degeneration masks, so each loses a different subset of sub-functions while the pair together still reproduces the old signature. The new copy specializes on the new data. Copies that end up redundant are pruned.
VALUE: New capabilities can grow after deployment, with old ones preserved in the network's structure rather than by penalties or replay.

F20
MECHANISM: Every internal quantity carries a vector of integer exponents over learned base "dimensions", like units in physics. Operations that mix incompatible dimensions are masked out. When data forces an inconsistent assignment, the system solves the integer linear system (Smith normal form) and adds a new base dimension. Predictions are made only through dimensionless groups found automatically, in the style of the Buckingham-pi theorem.
VALUE: Built-in sanity checks and principled extrapolation far outside the training range, because laws written in dimensionless form transfer across scales.

F21
MECHANISM: Every layer is a bijection, and any information a step would normally discard is written exactly to an ancilla tape. The tape's length measures how much was forgotten. Abduction runs the network backward: fix the desired output, edit the ancilla, and recover exactly which inputs would produce it. Unlearning removes one example's influence by un-computing its trace.
VALUE: Exact provenance, exact counterfactual inputs ("what would have had to be true?") and certified forgetting, none of which LLMs can do because they discard information at every layer.

F22
MECHANISM: To learn a new concept from a few examples, the system modulates the hypothesized feature (present or absent, at varying strength) across its inputs following a pseudo-random reference code. Per-channel integrators multiply each internal activation by the reference and low-pass the product, which pulls out the channels coherently locked to the concept even far below the noise. The locked channel set becomes a durable address for the concept. A new code then re-tests the address, and channels whose lock fades are dropped.
VALUE: Concepts can be isolated precisely from very few, noisy examples, with a signal-to-noise level that can be measured.

F23
MECHANISM: A bank of coupled phase oscillators (Kuramoto dynamics) runs continuously, and timestamped events phase-reset or nudge them. Concepts and routines are stored as stable phase-locking patterns between oscillators, not as static vectors. Each oscillator adapts its natural frequency to minimize phase error at event onsets, and an expectation is read out as the phase at which the next event should arrive.
VALUE: A real sense of duration, rhythm, deadlines and "something is late", including discovering hidden periodicities in event streams. Token-sequence models have no clock, so they cannot do this.

F24
MECHANISM: Many heterogeneous modules (search, simulation, symbolic solvers, small neural nets) bid for slices of a shared compute budget. A bid is priced by the expected reduction in task uncertainty, and the payout is the realized reduction. Modules that bid well gain budget and get copied with mutations, while chronically bad bidders are retired. The architecture is therefore an evolving economy rather than a fixed graph.
VALUE: It makes possible adaptive, open-ended allocation of reasoning effort and self-directed architectural growth after deployment.

F25
MECHANISM: Every double-entry balance identity is treated as a surveying condition equation. A least-squares adjustment runs over all transfers, and Baarda w-tests compare two kinds of explanation: "a blunder in step k" (a residual pattern local to one step) and "an unseen holder h" (one systematic pattern shared across many balance loops). Hidden holders are added the way self-calibration adds parameters: only when they pass a significance test and lower the minimal detectable bias of other claims. Variance-component estimation learns a reliability weight for each quantity, which continuously demotes a quantity toward "approximately conserved". Redundancy numbers point the planner to the claims nothing checks yet, and it then asks for or derives the one extra count that would close a loop around them. First test: Generate 500 synthetic multi-step transfer stories (bAbI-style ledgers) with one injected arithmetic blunder or one omitted holder each; run the adjustment with w-tests; success is ≥85% correct blunder-versus-holder classification and step localization, beating a largest-residual baseline by ≥15 points.
VALUE: The system can track world state over very long texts and say which step is wrong or which unmentioned participant must exist, with a stated confidence in each verdict.

F26
MECHANISM: The input layer has a variable width. When the system cannot reduce its loss on some quantity from its existing inputs, it writes and deploys an external probe: a code instrumentation hook, a sensor configuration, a lab-assay protocol or a database query. Whatever stream the probe produces is attached as a new typed input channel with its own learned encoder. Channels whose removal does not hurt downstream performance are pruned, so over time the system's perceptual alphabet becomes a set of instruments it designed itself.
VALUE: It can perceive and reason about quantities that no human ever chose to give it, instead of being limited to the fixed modalities it was trained on.

F27
MECHANISM: Before each background walk derives from a random fact partition, it publishes a salted hash of its forecast endpoint to an append-only log. The walk then reveals the forecast once it finishes. A conclusion's tally counts only confirmations of forecasts that were sealed by walks drawing on disjoint partitions, and passing the threshold freezes the conclusion into a primitive. A verifier dissolves primitives whose use correlates with forecast departures beyond what the evidence justifies. First test: On a synthetic knowledge base with planted circular-support conclusions (derivable only through mutually dependent rules), run hashed-forecast walks over random partitions. Success: disjoint-partition tallying rejects ≥90% of circular conclusions and freezes ≥80% of genuinely supported ones, against naive confirmation counting.
VALUE: Abstractions can grow without outside labels yet stay auditably free of self-confirming circular support.

F28
MECHANISM: Each query is answered through many short loops of different modules or routes (A→B, B→C, A→C, and inverse maps). For each loop the system computes the closure residual, in which each module's systematic error cancels. A least-squares solve over thousands of these triangles estimates and stores a bias term for each module. Those terms correct later outputs, and a large residual that remains after correction flags an unreliable answer.
VALUE: Error detection and correction become intrinsic and need no labels, because errors are attributed to specific components.

F29
MECHANISM: Concepts are stored as points in an embedding space, and each learned fact is a constraint between points (distance, angle or relation). The system keeps computing the rigidity matrix of this framework. Its null space gives "floppy modes", directions in which a concept can move without breaking any known fact, so the concept is underdetermined. Each floppy mode creates a bracing latent variable or a targeted query along that direction. Each state of self-stress (constraints that are redundant and in conflict) splits the stressed concept into two nodes, so that each one meets a consistent subset of the constraints.
VALUE: The system can tell, from the geometry alone, exactly which parts of its knowledge are underdetermined or overconstrained, and it repairs each part structurally.

F30
MECHANISM: Surprising experiences go verbatim into a fast episodic buffer. During offline phases the system replays them to propose weight deltas inside a sandboxed copy of its slow network. Each delta is accepted only if a self-maintained regression suite of past skills shows no loss, and rejected deltas are stored as interference records that shape later proposals.
VALUE: It enables continual lifelong learning after deployment without catastrophic forgetting.

F31
MECHANISM: Background walks count the routes to each conclusion, but routes are independent only if they rest on disjoint instrument lineages. When a conclusion is reached by many routes but relies on few instruments, the system writes and deploys a new probe (code hook, sensor setup, assay, query) designed to give a disjoint derivation path. Primitives are frozen only once they span ≥3 instruments. They store their instrument support and dissolve when a channel they depend on is pruned. Robust primitives are promoted into virtual input channels. First test: In a synthetic world with 10 latent variables seen through 20 channels that share injected lineage-specific artifacts, compare instrument-disjoint freezing plus probe synthesis with route-count freezing. Success: frozen primitives are at least 20 points more precise against the ground-truth latents.
VALUE: Without any external labels, it builds abstractions that are confirmed by independent measurement, and it designs its own instruments to check what it believes.

F32
MECHANISM: Provenance links every weight update to the user cohorts whose interactions it touched. Cohort adverse-event rates (corrections, re-asks, abandonments) become redundant meters in a weighted least-squares estimate of each update's harm coefficient. The largest normalized residual above 3 is attributed either to an update, which is scaled back in proportion to its estimated harm, or to a reporter cohort, which is re-typed as suspect and down-weighted. The system then re-estimates until all residuals pass. First test: Simulate continual LM fine-tuning over 50 updates and 200 synthetic cohorts, with 5 planted harmful updates and 3 colluding cohorts filing false adverse events. Success: WLS residual attribution finds both at F1 ≥0.9, scale-back restores held-out quality, and there are no false rollbacks.
VALUE: A continually learning model can roll back genuinely bad lessons while staying robust to coordinated or corrupt feedback that tries to trigger false rollbacks.

F33
MECHANISM: During latent multi-step reasoning, the system computes the condition number of its step map's Jacobian. When it crosses a threshold, the system switches to a stored invertible reparameterization (a chart) and rescales its step size as celestial mechanics does with KS regularization. New charts and transition maps are learned where singularities keep recurring, building an atlas.
VALUE: Reasoning stays stable through near-singular regions, where today's models silently degrade.

F34
MECHANISM: Background random walks keep re-deriving conclusions from stored facts along many different routes. A tally records how many independent routes reach each conclusion (routes sharing no intermediate fact count separately). When the tally passes a threshold, the conclusion is frozen into a new atomic primitive that later walks can use as one step. Primitives that are no longer reachable by several routes are dissolved back into their parts.
VALUE: It builds new concepts from how well a conclusion is held together by the rest of what it knows, with no outside feedback, so abstraction can grow in domains where nothing ever says "correct."

F35
MECHANISM: When prediction error on an input crosses a learned threshold, the system writes a small key-value module next to the frozen core. The key is the context embedding and the value is a low-rank change to the core's weights. Those changes take effect only when a later context is similar to that key. During an offline phase, the system replays old episodes against the patches. It merges patches that do the same thing and deletes ones that conflict, using how often they agree as the score. Each patch keeps a count of how often it was used and how often it was confirmed, and patches that stop earning their place are removed.
VALUE: The system could learn permanently from a single experience without forgetting what it already knows or needing retraining.

F36
MECHANISM: A query is turned into a set of variables, which are partial answers and sub-goals, plus constraints between them that are learned or extracted from the query. Local update rules pass messages between these units, and the system keeps iterating until either a symbolic checker or a learned checker confirms that every constraint is met, or the energy of the system stops falling. When progress stalls, the system adds intermediate variables, for example lemmas or sub-plans, and stores successful arrangements as reusable templates.
VALUE: The system could spend compute in proportion to how hard a problem is and solve multi-step problems it cannot solve in one pass, with a clear signal for when it has succeeded and when it has failed.

F37
MECHANISM: Each experience is logged as an ordered sequence of operations. A background process swaps neighbouring pairs and tests whether the resulting record is identical. Operations that always commute are split into separate parallel threads with no shared state. Operations that never commute are fused into one indivisible unit, so the system's architecture becomes a map of the world's independence structure.
VALUE: The system can split the world into independent parts and recombine them freely, which gives built-in compositional generalization.

F38
MECHANISM: An embedding-indexed map stores the system's ground-truth-verified error statistics for each region of problem space, updated whenever an outcome is checked. Before answering, the system looks up the query's region. It then answers, abstains, asks for information, or routes the region to the learning loop, depending on the measured reliability and the cost of being wrong.
VALUE: It gives reliable self-knowledge of where the system is competent, so it can abstain and direct its own learning based on its actual track record.

F39
MECHANISM: Perception updates a running graph of objects, their attributes and typed causal links. Each link carries a probability and a count of how many times its predictions came true. Before each step the system simulates what it expects to observe, then compares that with what it actually observes. When they differ, it traces the error back through the graph to the links most to blame and revises them: it adds hidden variables, splits links or reverses their direction. It can also run interventions inside the graph to test competing explanations before acting.
VALUE: The system could know when its beliefs are wrong, reason about counterfactuals, and keep a consistent, inspectable model of the world over long periods.

F40
MECHANISM: The system continuously runs the four-point condition on embedding distances among concepts in its taxonomy. Quartets that violate it point to hybrid concepts, and those concepts are re-typed as reticulation nodes with two weighted parent lineages. Properties are then inherited from both parents. The violation magnitudes are stored, and edges are reweighted as evidence accumulates. First test: Using WordNet/Wiktionary-etymology concepts with ~200 labeled hybrids (loanword blends, hybrid species, fusion genres) and matched non-hybrids, compute four-point-condition violations on off-the-shelf embedding distances; success is AUROC ≥0.75 for flagging hybrids and higher property-prediction accuracy than single-parent tree inheritance.
VALUE: The system can represent and reason about concepts that blend lineages, such as loanwords, hybrid organisms or mixed genres, which strictly tree-shaped hierarchies get wrong.

F41
MECHANISM: The system keeps an ensemble of perturbed copies of a set of adapter parameters. Each new observation is assimilated by a Kalman-gain update computed from the ensemble's covariance between parameters and predictions; no gradients are used. The gain is tapered by distance in representation space, so an update only shifts parameters that covary with nearby inputs. Inflation keeps the ensemble's spread from collapsing.
VALUE: The system can learn continuously from single examples while deployed, with interference limited by construction rather than by replay.

F42
MECHANISM: The system logs experience as operation sequences and tests adjacent swaps. When a pair's commutation can't be decided from current inputs, it designs a probe (hook, query, sensor setting) that observes the intermediate state, and attaches the probe as a typed channel. Deployed probes are themselves logged as operations. A probe that fails to commute with what it observes is marked invasive and fused with that process, while non-invasive probes stay as free parallel channels. A channel is pruned when removing it leaves every commutation verdict unchanged. First test: Simulate a pipeline of 12 processes with known commuting structure, where some states are visible only through optional probes and two probes perturb state, and run swap tests with probe design. Success: the true commutation graph is recovered and both invasive probes are flagged with zero false positives.
VALUE: The system builds its own perception around the world's independence structure and knows which of its measurements disturb what they measure.

F43
MECHANISM: Each weight update carries a provenance ID and is linked to the interactions it influenced. User corrections, re-asks and abandonments count as adverse events. A proportional reporting ratio with the Evans thresholds flags harmful updates, which are subtracted partially or fully in proportion to the signal.
VALUE: A continually learning system can withdraw its own bad lessons, judged by evidence from real use.

F44
MECHANISM: Before the system sees evidence or produces a reasoning trace, it must publish a cryptographic hash of its quantized answer distribution, plus a salt, to an external log it cannot change. After the evidence arrives, it reveals the commitment. An independent verifier then checks whether the final answer departs from the committed one more than the evidence statistically justifies. Training penalizes departures without justification and rewards accurate commitments, so the architecture learns to keep "what I believed beforehand" separate from "what I can rationalize afterward".
VALUE: Third parties can check that the system is not rewriting its beliefs after the fact, which is a property no current LLM can prove about itself.

F45
MECHANISM: A background process fits small Lie-algebra generators (infinitesimal transformations) to the system's own learned input-output dynamics and keeps those under which predictions stay unchanged. For each symmetry that survives, it derives the matching conserved quantity, stores it as a named variable, and enforces it as a hard projection on every later output. When new data breaks a conserved quantity, the system demotes that symmetry and searches for a narrower one that still holds. First test: Train an MLP dynamics model on short-horizon 2D spring-mass and N-body trajectories, fit Lie generators and project outputs onto the conserved quantities found. Success: rollout error at 10x horizon and at unseen energies is at least 5x below unprojected and HNN baselines.
VALUE: Lets the system extrapolate far outside its training distribution by reasoning from discovered conservation laws instead of memorized patterns.

F46
MECHANISM: The system keeps a growing library of small probabilistic programs, each encoding a candidate causal mechanism (e.g., "pressure causes leak if seal is worn"). When several programs explain the observations equally well, it computes which intervention (real action, simulator query or tool call) would best tell them apart, runs it, and reweights or deletes programs based on the result. New programs are synthesized by recombining fragments of programs that survived, so the library compresses over time.
VALUE: It can discover and reliably use real cause-and-effect structure, including in situations that never appeared in its data.

F47
MECHANISM: Each proofreading stage re-encodes the context with a learned map (paraphrase, abstraction, dropout). A step's binding margins across these encodings therefore form edge flows on a cycle complex, and a Hodge decomposition splits them into three parts. The gradient part is encoder bias: correct the map and keep the step. The curl part is real fragility: discard the step irreversibly. The harmonic part means the step holds only in some contexts: commit it locally to a new chart, with an explicit context variable and a transition map. Later steps that cross chart boundaries face extra proofreading stages, scaled to the misclosure of the transition map they cross. A new chart is kept only if steps committed in it survive this proofreading. First test: On 500 GSM8K chains plus 200 synthetic problems whose steps hold only under one of two stated rule sets, score steps under four re-encodings and Hodge-split the margins; success is lower final-answer error than majority-vote proofreading while retaining ≥90% of context-conditional true steps.
VALUE: Error rates in long reasoning drop exponentially without discarding conclusions that are true only in some contexts, and the system learns where its knowledge splits into separate frames.

F48
MECHANISM: Every assertion the system adopts becomes a node in a persistent graph that stores its source, confidence and the nodes it was derived from. On each inference step a constraint checker scans for contradictions. Conflicts are resolved by retracting the least-supported justification, and the retraction automatically propagates to all dependent conclusions (truth maintenance). Generation is restricted to drawing on the active ledger and has to cite node IDs.
VALUE: It enables lifelong learning without catastrophic forgetting, with traceable reasoning and instant correction of any fact and everything derived from it.

F49
MECHANISM: The system keeps about 64 copies of a "knowledge state", which is a subset of its parameters. Each new fact or correction is handled as a weather-style observation. The update gain comes from the copies' cross-covariance between parameters and their predictions of that fact. A learned taper limits the update to parameters close to the fact in concept space, which stops a new fact from overwriting distant ones. When the copies agree too much, they are spread apart again so the system can keep learning.
VALUE: The system can absorb a stream of new facts and corrections, each with a real confidence level, without retraining, and without the long-range damage that causes forgetting.

F50
MECHANISM: The reasoning state is an e-graph that holds all known equivalent descriptions of the problem at once, with no destructive rewriting. Rewrite rules mined from solved episodes are applied until saturation or until a budget runs out. The system then extracts the representation with the lowest cost under a learned "solvability" cost. New rules are added when an extracted form leads to success.
VALUE: Unfamiliar problems become solvable when some equivalent re-description reaches already-mastered territory, and rules combine across domains.

F51
MECHANISM: Knowledge is a pool of symbolic "species" at varying concentrations, plus rewrite reactions that consume some species and produce others. Each cycle, every species is diluted at a fixed rate. It survives only if the reactions it takes part in regenerate it. New reactions come from random recombination, and the set that persists is whatever forms closed, self-maintaining loops.
VALUE: Concepts are defined by the network of processes that keep producing them, which gives self-sustaining, open-ended structure without any objective.

F52
MECHANISM: Each intermediate claim is a "station" that is derived along at least two independent routes, so the routes form closed loops. Each loop has a computed mismatch (misclosure). A least-squares adjustment spreads small mismatches across the loop, and Baarda's w-test singles out the one derivation step that is a blunder. Each claim gets a redundancy number. Any claim with a value near zero is unchecked, so the planner deliberately adds a new route to it before answering.
VALUE: Long chains of reasoning check themselves. The system can say which step is wrong and which conclusions nothing has verified yet.

F53
MECHANISM: Holders are learned points, and each transfer is a bar between two of them. A balanced set of transfers is an equilibrium stress, so a quantity counts as conserved only while its transfers stay in that stress space. An imbalance that won't go away is treated as a load on the framework. The system adds a hidden holder at the position where the loose directions (floppy modes) can absorb that load. Where stresses conflict, the holder splits in two. First test: On synthetic ledger worlds with 10–30 holders where 1–3 holders are removed from the transfer log, fit the bar-framework stress model; success is ≥80% recovery of hidden-holder count and their transfer partners, beating a per-holder imbalance-threshold baseline.
VALUE: The system can keep exact track of world state, and the geometry shows where unknown participants must be and which quantities are not really conserved.

F54
MECHANISM: The latent space is divided into cells, each holding its own local linear map. For each cell, a Zienkiewicz-Zhu-style estimator compares the cell's Jacobian with the Jacobian recovered from its neighbours. Cells whose discrepancy is above 2x the mean are split into children with new maps, and calm siblings are merged. Resolution grows only where distinctions actually change.
VALUE: It can tell apart near-identical cases with different outcomes, without uniform scaling or labelled error.

F55
MECHANISM: Claims are nodes, and derivations are edges that carry transformations; whatever error is left after going round a loop is that loop's misclosure. When the Hodge split finds a harmonic residual, the system doesn't accept it as a real gap straight away. First it builds bridging derivations across the gap, choosing them with Baarda's minimal-detectable-bias so that each new derivation best tells the possible explanations apart. If the new pieces bring the error back to zero, it was a mistake, and the w-test finds the bad step. If the error survives every bridge, the system creates a new context variable that splits the claims into separate frames. First test: Build 300 synthetic claim graphs of unit-conversion derivations whose loops misclose either from one injected wrong step or from a hidden two-frame split (two exchange-rate regimes); success is ≥85% correct mistake-versus-frame verdicts with correct step localization, beating treating every harmonic residual as a gap.
VALUE: The system can tell a mistake in its own reasoning apart from a real need for separate frames, and it finds out by running its own test.
