F01
MECHANISM: For each claim the system relies on, it spawns a tiny, freshly initialised adversary on a budget. The adversary searches for inputs, rephrasings or contexts in which the system contradicts that claim. The amount of compute the adversary needed before it succeeded is stored with the claim as a "breaking price". Downstream reasoning may only build on claims whose price is above a threshold set by how much is at stake. Claims that break cheaply are flagged for targeted retraining using the counterexamples the adversary found.
VALUE: Robustness becomes a quantity the system measures for each belief and can act on, instead of a property it hopes it has.

F02
MECHANISM: A query is turned into a set of variables, which are partial answers and sub-goals, plus constraints between them that are learned or extracted from the query. Local update rules pass messages between these units, and the system keeps iterating until either a symbolic checker or a learned checker confirms that every constraint is met, or the energy of the system stops falling. When progress stalls, the system adds intermediate variables, for example lemmas or sub-plans, and stores successful arrangements as reusable templates.
VALUE: The system could spend compute in proportion to how hard a problem is and solve multi-step problems it cannot solve in one pass, with a clear signal for when it has succeeded and when it has failed.

F03
MECHANISM: Perception updates a running graph of objects, their attributes and typed causal links. Each link carries a probability and a count of how many times its predictions came true. Before each step the system simulates what it expects to observe, then compares that with what it actually observes. When they differ, it traces the error back through the graph to the links most to blame and revises them: it adds hidden variables, splits links or reverses their direction. It can also run interventions inside the graph to test competing explanations before acting.
VALUE: The system could know when its beliefs are wrong, reason about counterfactuals, and keep a consistent, inspectable model of the world over long periods.

F04
MECHANISM: Every internal quantity carries an exponent vector over a growing set of base kinds, and operations may only combine compatible vectors. The system keeps rescaling or swapping kinds in its own inputs and checks that its outputs change exactly as the exponents predict. Each failure splits a kind, adds a new one, or revises an exponent.
VALUE: Reliable extrapolation far beyond the magnitudes in its experience, plus automatic detection of answers that make no sense.

F05
MECHANISM: Input edits are applied at graded strengths, and each edit-effect cluster gets a kind-exponent vector inferred from the log-log slope of the frozen predictor's response. Clusters cannot mix incompatible exponents. Each second-order interaction is checked for multiplicative composition: a pass makes a typed link, and a failure splits the cluster into two new kinds. The stored kinds, exponents and edit library are refit as new inputs arrive.
VALUE: It finds dimension-like variables directly in raw text, pixels or sensor data, which supports extrapolation and sanity checks on answers in domains that have no unit system.

F06
MECHANISM: Surprising experiences go verbatim into a fast episodic buffer. During offline phases the system replays them to propose weight deltas inside a sandboxed copy of its slow network. Each delta is accepted only if a self-maintained regression suite of past skills shows no loss, and rejected deltas are stored as interference records that shape later proposals.
VALUE: It enables continual lifelong learning after deployment without catastrophic forgetting.

F07
MECHANISM: An invertible reasoner reconstructs its inputs from the answer under many premise subsets, and the reconstruction gap between each pair of subsets is stored as a flow on a graph. A Hodge decomposition splits these flows. The gradient part is surfaced as one explicit missing assumption. The curl part marks a term whose meaning shifts around the cycle, so that concept is split along a new latent context axis. The new axis becomes a premise slot that the next backward pass must fill.
VALUE: The system can tell an argument that rests on an unstated assumption from one that quietly changes what a word means.

F08
MECHANISM: Training data is split into hashed provenance shards (one per source or document cluster). Each shard trains its own low-rank weight delta on a frozen base. At inference the deltas are combined additively, with input-dependent coefficients produced by a small probe. That probe is trained on held-out data to predict which shard's evidence an answer actually needs, so each output carries a list of the shards that contributed. A source is removed by deleting its delta, and a disputed fact can be re-checked by switching shards off and seeing whether the answer survives.
VALUE: Knowledge becomes traceable to its sources and exactly removable, so the system can say where a belief came from and forget it on demand without retraining.

F09
MECHANISM: When prediction error on an input crosses a learned threshold, the system writes a small key-value module next to the frozen core. The key is the context embedding and the value is a low-rank change to the core's weights. Those changes take effect only when a later context is similar to that key. During an offline phase, the system replays old episodes against the patches. It merges patches that do the same thing and deletes ones that conflict, using how often they agree as the score. Each patch keeps a count of how often it was used and how often it was confirmed, and patches that stop earning their place are removed.
VALUE: The system could learn permanently from a single experience without forgetting what it already knows or needing retraining.

F10
MECHANISM: Every assertion the system adopts becomes a node in a persistent graph that stores its source, confidence and the nodes it was derived from. On each inference step a constraint checker scans for contradictions. Conflicts are resolved by retracting the least-supported justification, and the retraction automatically propagates to all dependent conclusions (truth maintenance). Generation is restricted to drawing on the active ledger and has to cite node IDs.
VALUE: It enables lifelong learning without catastrophic forgetting, with traceable reasoning and instant correction of any fact and everything derived from it.

F11
MECHANISM: For each module, the system tests whether paired feature co-activations match the products of their marginal frequencies. A heterozygote-like deficit indicates two pooled subpopulations, so the module splits in two, inputs are assigned by admixture inference, and a router is learned. Over time, splits build a lineage tree of specialized modules.
VALUE: The architecture adds specialists when a statistic shows a module has been mixing two input types.

F12
MECHANISM: A candidate inference step must survive K sequential, irreversible holding stages before it is committed. At each stage it is re-tested for match against an independently perturbed context, and if it detaches it resets to the beginning rather than to the previous stage. Errors therefore decay roughly as f^K. The number of stages a candidate survives gives a confidence score, and the system can raise K wherever stakes are high.
VALUE: Reasoning accuracy can be bought with compute in a predictable, near-exponential way, instead of being capped by a single forward pass.

F13
MECHANISM: The system keeps one separate copy of the world state for each agent in a scene, plus one ground-truth copy. Events are sent through gated channels, and a copy is updated only if a learned visibility function says that agent saw or was told about the event. Unseen events leave the copy stale on purpose. Nested copies, meaning what agent A holds about agent B's copy, are created on demand down to a fixed depth. The visibility function is trained on the mismatch between the actions a copy predicts for its agent and the actions that agent actually takes.
VALUE: The system can track false and nested beliefs reliably across long stories, negotiations and deception.

F14
MECHANISM: A candidate step does not commit right away. It passes through k timed holding stages, and each stage re-scores it under a freshly perturbed context. A candidate drops out at each stage with an off-rate that grows exponentially as its support margin falls; a candidate that drops out restarts from scratch rather than going back one stage. The value of k and the compute spent per stage are set according to how much is at stake in the step.
VALUE: Error per step falls exponentially with the compute spent, so long chains of reasoning stay reliable instead of degrading.

F15
MECHANISM: Candidate partial answers are injected as phase-coded waves into a grid of oscillating cells. Contradictory candidates get opposite phase and cancel, while mutually consistent ones reinforce into standing peaks. Cells that repeatedly hold strong amplitude stiffen, cutting lasting channels that bias future propagation. The stable peak pattern is read out as the answer.
VALUE: Many alternatives can be searched at the same time, with inconsistency removed physically rather than candidate by candidate.

F16
MECHANISM: Concepts are joints and learned relations are bars. The system periodically computes the spectrum of the rigidity matrix. Floppy modes trigger acquisition of new bracing relations, and self-stress states split the node along the eigenvector of the stress. The concept frame is stored, and it grows or splits as these spectral tests fire.
VALUE: The system can find for itself which concepts are underdetermined and which are conflated, and repair them.

F17
MECHANISM: Each reasoning step is treated as a survey observation with a variance. The planner deliberately builds redundancy by deriving key quantities along independent routes so the steps form closed loops. Least-squares adjustment spreads each loop's misclosure across the steps, and Baarda's w-test flags the step with the largest standardized residual. Only that step is re-derived, and the planner adds redundancy where the redundancy numbers show steps that cannot be checked.
VALUE: Long chains locate their own blunders and design themselves to be checkable, so errors do not silently compound.

F18
MECHANISM: During training, each distinct data stream (a corpus, a school of thought, a language community) writes into its own separate low-rank weight delta, so the model is stored as a base plus a ledger of experience deltas. At inference the system can add, remove or reweight deltas to bring up "counterfactual selves" that would have existed under a different upbringing. It runs these selves side by side and computes a structured diff of their beliefs. The ledger keeps growing as new streams arrive, and each stream stays a separable entry.
VALUE: It can answer "what would I believe if I had never read X, or had grown up on Y instead?", tracing a conclusion back to the experiences that formed it.

F19
MECHANISM: For each query, the system draws several decorrelated derivations, each with a different decomposition, persona, or retrieval seed. It clusters the considerations, candidate answers and counterexamples they produce, then computes Chao1 and Good–Turing estimates from the singleton and doubleton counts. The result is an estimate of the probability mass of relevant items it has not yet seen. Search continues until estimated coverage passes a target, and the output reports that remaining unseen mass.
VALUE: It gives the system a quantitative sense of how much it has not yet considered, which tells it when to stop searching and when to flag an answer as incomplete.

F20
MECHANISM: Many heterogeneous modules (search, simulation, symbolic solvers, small neural nets) bid for slices of a shared compute budget. A bid is priced by the expected reduction in task uncertainty, and the payout is the realized reduction. Modules that bid well gain budget and get copied with mutations, while chronically bad bidders are retired. The architecture is therefore an evolving economy rather than a fixed graph.
VALUE: It makes possible adaptive, open-ended allocation of reasoning effort and self-directed architectural growth after deployment.

F21
MECHANISM: The system keeps a growing library of small probabilistic programs, each encoding a candidate causal mechanism (e.g., "pressure causes leak if seal is worn"). When several programs explain the observations equally well, it computes which intervention (real action, simulator query or tool call) would best tell them apart, runs it, and reweights or deletes programs based on the result. New programs are synthesized by recombining fragments of programs that survived, so the library compresses over time.
VALUE: It can discover and reliably use real cause-and-effect structure, including in situations that never appeared in its data.

F22
MECHANISM: Before an outcome is observable, the system publishes cryptographic hash commitments of its predictions to an append-only external log. It reveals the predictions only after the outcome has resolved. The resulting record cannot be altered after the fact, and the system uses it as its only source of reward: learning updates are weighted by forecasts that were verifiably committed in advance, never by hindsight explanations. Outside parties can stake on, or audit, any category of prediction. Their challenges become extra training signal.
VALUE: Trust and learning are anchored in a track record that neither the system nor its trainers can rewrite after the fact.

F23
MECHANISM: An internal concept is kept only if it passes a transmission test. The system compresses the concept into a short message, and a freshly initialised learner with a different architecture, given only that message plus a few examples, must succeed on held-out tasks. Concepts that fail are rewritten or dropped. The surviving messages are stored as the system's vocabulary of abstractions and get re-tested whenever the pool of naive learners is refreshed.
VALUE: The system ends up holding abstractions that are explainable and transferable by construction, rather than private features entangled with one particular network.

F24
MECHANISM: The system computes the Allan deviation of its prediction residuals across context lag. When the deviation rises at τ\*, it creates a new recurrent state with time constant τ\*. It keeps that state only if the rise in deviation flattens afterwards.
VALUE: Memory gets exactly the timescales that the data's hidden drift requires.

F25
MECHANISM: Knowledge is stored as many small content-addressed entries rather than shared weights. Each entry holds monotone state: grow-only evidence counters, last-writer-wins registers with vector clocks, and sets of exceptions that support adding and removing. Each deployed copy updates its own replica from its own experience, and replicas combine through the lattice join, so merges never conflict and never depend on order. Retractions are tombstones, and prediction reads the joined state.
VALUE: Millions of copies can learn from separate experiences and pool what they learned exactly, with no catastrophic interference.

F26
MECHANISM: Each derivation step is built from operations that can be run in reverse. Information a step cannot reverse is written to an explicit residual register instead of being thrown away. After producing an output, the system runs the chain backward to rebuild the inputs. Residual bits that the inputs cannot account for mark exactly the spans where new content was added rather than derived. Training lowers the count of unexplained residual bits for each claim, and outputs are labelled by how much residual they carry.
VALUE: Each statement can be checked mechanically to show whether it follows from the given material or was made up.

F27
MECHANISM: Closes G2. For each real task type, the system builds twin tasks in the easy direction, where the answer is fixed first and the problem is generated from it: run a program and then ask for its output, hide a known span and then ask to reconstruct it, compose a plan and then ask what goal it achieves. A discriminator is trained adversarially until it cannot tell the twins from real tasks. The system stores per-twin-cluster accuracy for every checker and solver. On a real task with no oracle, the correctness estimate is the measured accuracy on the twins that match it most closely.
VALUE: It gives a calibrated, always-available correctness signal on tasks where no verified outcome will ever arrive.

F28
MECHANISM: Known-answer twins are generated from fixed answers. Each twin is then pushed through the learned kind-exponent algebra (rescalings and kind swaps) to make an orbit of further known-answer twins at magnitudes the system has not seen. Accuracy is stored per twin cluster and per orbit distance. When a real task's output breaks the change its exponents predict, the matched twin decides the cause: a correct twin that still breaks it means the algebra is wrong (split a kind or revise an exponent), and a wrongly solved twin means the solver is wrong (lower that cell's accuracy).
VALUE: Calibrated correctness estimates that reach into extrapolation regimes, plus a units algebra that can tell its own errors apart from solver errors.

F29
MECHANISM: Every retained lesson must also run as an answer-first generator of twin tasks, and a fresh student taught only that lesson is scored on them. A discriminator assigns each real task to the lesson whose twins it cannot tell apart from it, and that student's twin accuracy is the correctness estimate for the real task. Lessons with twins that are easy to distinguish are rewritten or pruned. Real tasks that no lesson can imitate are marked as untaught territory for writing new lessons.
VALUE: It gives a calibrated correctness signal with no oracle, together with a map of what the system's explicit knowledge does not yet cover.

F30
MECHANISM: The model learns transformation maps between concepts and contexts. It decomposes them by Hodge decomposition to find cycles whose sum is not zero. Where curl persists, it adds a new latent context dimension and splits the concept along it until the cycles close. The split concepts are stored with the cycle that triggered them.
VALUE: The model finds ambiguities it was not told about and gives each meaning its own concept, instead of averaging two incompatible ones.

F31
MECHANISM: Reasoning runs on reversible operations; the forward pass logs bits it cannot reverse in a residual register (added content), and the backward pass from answer plus premises measures input-reconstruction deficit (assumed content). Residual spans are decoded into candidate premise sentences and fed into the backward pass. A candidate becomes a stated assumption only if it closes a matching part of the deficit. Residual that closes no deficit is labelled fabricated, and deficit left unexplained triggers retrieval or a question to the user. Training minimises the bits left unmatched on both sides.
VALUE: Hidden assumptions and made-up claims are worked out mechanically and turned into explicit premises that can be tested, rather than being guessed from confidence scores.

F32
MECHANISM: Every derivation path to a candidate answer contributes a complex amplitude, and the path's phase is set by the assumptions it relies on. Paths that support an answer through incompatible assumptions cancel each other out, while paths that agree reinforce each other. The final confidence is the squared magnitude after summing. The phase assignments are learned, so that recurring conflicting assumption pairs become orthogonal or opposed.
VALUE: The system can represent "many reasons that cancel out" as real uncertainty, which averaging probabilities cannot express, so it stops being overconfident when it has many weak, conflicting justifications.

F33
MECHANISM: Before an inference step is committed, it must survive K irreversible stages. Each stage applies an edit from a different discovered effect cluster, going from far to near in the link graph, and any detachment resets the step to stage one. Each committed step stores its survival profile as a scope, meaning the variables it has been shown not to depend on, and steps can combine only when their scopes are compatible. When an edit keeps detaching steps even though the clustering marked its cluster as unlinked, the clustering is refit: that cluster is split or a typed link is added.
VALUE: Reasoning steps that come with an explicit, tested record of what they do not depend on, while the input's variable structure keeps getting corrected by the reasoning's own failures.

F34
MECHANISM: An embedding-indexed map stores the system's ground-truth-verified error statistics for each region of problem space, updated whenever an outcome is checked. Before answering, the system looks up the query's region. It then answers, abstains, asks for information, or routes the region to the learning loop, depending on the measured reliability and the cost of being wrong.
VALUE: It gives reliable self-knowledge of where the system is competent, so it can abstain and direct its own learning based on its actual track record.

F35
MECHANISM: A candidate reasoning step with its one-line justification is committed only after K fresh students in a row, each smaller than the last, reproduce it from the current lessons alone. Any failure resets the step to stage 0 and forces its justification to be rewritten. The number of stages survived is stored as a graded legibility and confidence score, and K is raised for steps that many later steps depend on.
VALUE: Accuracy can be bought with compute while keeping every committed step explicit and teachable to a small mind.

F36
MECHANISM: The system maintains a population of small probabilistic programs, each a candidate simulator of some part of the environment. Queries are answered by running or intervening on the best-scoring simulators. Prediction errors drive program-synthesis mutations, and simulators are selected by how well they compress observations and predict accurately.
VALUE: It gives explicit causal and counterfactual reasoning and lets the system discover new models that can be inspected.

F37
MECHANISM: Inference runs deterministically on quantized arithmetic, so any internal state can be replayed exactly. A commitment register stores cryptographic hashes of chosen latent plans, predictions or intentions at the moment they are formed. A policy layer is trained to be penalized for actions that conflict with open commitments. Later the system can reveal a commitment and prove by replay, or with a zero-knowledge proof, what it believed or intended at that earlier time.
VALUE: It lets an AI make credible precommitments, sealed bets and verifiable promises to people or other AIs, opening up negotiation, contracts and game-theoretic coordination it cannot take part in today.

F38
MECHANISM: Each deployed copy stores concepts as short messages. One message ranks above another if a fresh learner with a different architecture, taught only that message, passes all of the other message's held-out tasks. A join is the shortest message that teaches both, found by compressing them together. When no such message is found, the two are kept as tombstone-safe sibling branches with grow-only evidence counters. Counter growth triggers retesting against a refreshed pool of naive learners, and a branch that no longer teaches is retracted by a tombstone.
VALUE: Millions of copies can pool what they learned into shared abstractions that stay explainable, and they never blend incompatible ones.

F39
MECHANISM: Reasoning steps form redundant closed loops, adjusted by least squares. Baarda's w-test plus re-derivation sorts each misclosure: if it moves to one step and disappears on re-derivation, that step is a blunder and is fixed; if it stays spread evenly around the cycle, larger than any single step's minimal detectable bias, it is curl, and the concept is split along a new latent context dimension. Each split adds nodes with no redundancy yet, so the planner must build new independent routes that tell the two meanings apart before either can be used. The split concepts are stored with their triggering cycle and their reliability numbers.
VALUE: Long reasoning chains can tell their own arithmetic slips apart from real hidden ambiguities, fixing the first and splitting the second, instead of averaging them away or repeating the same wrong fix.

F40
MECHANISM: Closes G1. The system does not parse the input directly. It applies a large set of small edits to the raw input (swapping a token or phrase, inpainting an image patch, shifting time) and records how each edit changes a frozen predictor's output distribution. Edits are clustered by their effect signature, and each cluster becomes one variable whose values are the observed edit outcomes. A typed link is added wherever a pair of clusters shows a non-additive second-order effect, meaning editing both does not equal the sum of editing each. The edit library and clusters are stored, and the clustering is refit as new inputs come in, so the structured form is built from the input itself rather than hand-specified.
VALUE: It turns "parse the input into the representation" into a measurable procedure that works the same way on text, pixels and sensor streams.

F41
MECHANISM: Failures are logged as "mutants," and pairs are crossed by swapping internal states between their runs. Pairs that fail to recover are grouped as sharing one unit. A unit that holds failures from unrelated groups is split and its connections are reassigned. The stored complementation table grows over time and guides later splits.
VALUE: The modular structure follows the real fault lines of what the model can and cannot do, so a fix in one place does not break something else.

F42
MECHANISM: Each key quantity is derived by two or more reversible routes, and each route writes the bits it cannot reverse into a residual register. Each route's residual is fed into the backward pass of the other routes. Bits that no route can rebuild form the loop's misclosure, and that misclosure is measured in bits. A Baarda-style test, weighted by each step's residual size, flags the single step that is invented rather than derived. The planner then adds new independent routes where residual bits cannot be cross-checked by any other route.
VALUE: A long chain can find exactly which step introduced unsupported content and can build itself to be checkable.

F43
MECHANISM: Every layer and every reasoning step is a bijection, built from invertible couplings with explicit "garbage" registers, so each output can be run backward exactly to the inputs and training examples that produced it. Learning is done as reversible updates that are logged as compact inverse operations. To forget a datum, or to undo a conclusion, the system uncomputes the matching update chain instead of retraining. Nothing is erased irreversibly, so in principle the system also runs near the thermodynamic limit.
VALUE: Exact, verifiable unlearning and bit-level provenance for any output, which approximate gradient-based models cannot give.

F44
MECHANISM: Closes G4. Every cutoff (surprise, "similar enough", "least-supported", stopping tolerance) is replaced by an online conformal p-value. The p-value is computed against a null distribution built from shuffled, time-reversed or context-permuted copies of the system's own recent data stream. All thresholds draw on one global error budget using alpha-investing. Each test spends some of that budget to fire, and it earns budget back when a firing is later confirmed useful by downstream prediction gain, so cutoffs tighten or loosen automatically as conditions change. The stored state is only the per-test null samples and the current wealth balance.
VALUE: Behavior that used to depend on hand-tuned constants becomes self-calibrating with a guaranteed bound on the total false-alarm rate, including in a new domain with no history.

F45
MECHANISM: Knowledge is also held as short, explicit lessons. Periodically a small, empty student is rebuilt using only those lessons and scored on held-out cases. Lessons linked to the student's failures are rewritten or split, and lessons whose removal leaves the score unchanged are deleted. The size of the gap between the system's accuracy and the student's drives the rewriting.
VALUE: Unspoken, unexplainable competence becomes explicit, checkable knowledge that can be passed on, so the system knows which of its skills it actually understands.

F46
MECHANISM: Each feature's variance is split into run-to-run noise, surface-form variance and content variance. Features above a GRR threshold are re-typed as nuisance channels. Downstream reads move to rebuilt content-only features, and GRR scores are stored and checked again over time.
VALUE: Reasoning runs only on features shown to measure content, which removes failures caused by sensitivity to phrasing.

F47
MECHANISM: Every latent quantity carries a learned vector of integer "dimension" exponents. These are inferred so that every observed relation is dimensionally homogeneous, by keeping the dimension matrix's integer nullspace consistent across relations. Learned laws are stored only as functions of the dimensionless groups the Pi theorem derives from that matrix. When no consistent assignment exists, the system takes it as a sign of a missing hidden quantity and introduces one.
VALUE: A relation learned in one regime transfers exactly to unseen scales and configurations that share the same dimensionless groups.

F48
MECHANISM: Every learned concept gets an identifier tied to a frozen type specimen: one stored input plus the internal state it produced. Concept regions may drift, split or merge as new data arrives. On a split, the identifier follows the part that contains the type specimen, and the other part gets a new identifier. On a merge, the older identifier wins. Downstream skills cite identifiers, not weights, so they re-resolve through the types and keep working after revisions.
VALUE: It allows open-ended concept revision without silently breaking the skills and inferences built on older concepts.

F49
MECHANISM: A slow, general deliberative solver handles new problems and records the step trace it executes. When a trace becomes hot, it is compiled into a fast specialized routine with explicit guard predicates, which are the input conditions the trace assumed. At runtime, a failed guard falls back to the solver and increments a counter on that exit. An exit that keeps failing is compiled into its own child trace, so the trace tree grows and existing traces are never overwritten.
VALUE: The system gains new skills from a few experiences, with no gradient retraining and no forgetting, because old traces stay intact behind their guards.

F50
MECHANISM: Representations are held as the phases and amplitudes of a large bank of coupled oscillators, not as static vectors. Inputs drive phase-locking, and the outputs are emitted at moments set by phase alignment rather than by a request-response cycle. Coupling strengths adapt from phase error against external rhythms such as speech cadence, music or other agents' actions. Learned coupling patterns are stored as reusable "groove" templates.
VALUE: It can act as a real-time timing partner that shares tempo with humans or other agents in improvisation, joint movement and overlapping conversation, not just answer prompts.

F51
MECHANISM: Every internal numeric slot carries a short integer vector of exponents over a few base "kinds". Multiplying two slots adds their vectors. Adding or comparing two slots is only allowed when their vectors are identical, and a mismatch stops the step and raises a flag. Tag vectors are not hand-assigned. Across many episodes the system searches for products of observed quantities that stay constant, and it solves an integer linear system so that those products come out with a zero vector. Each repeated mismatch flag is a signal to refine the base kinds, by splitting one or adding one.
VALUE: Reasoning can no longer produce results that combine incompatible kinds of quantity, and the system finds conserved combinations in raw measurements on its own.

F52
MECHANISM: A capability counts as kept only if the system can write a short, human-readable lesson that lets a fresh, small, randomly initialized student reach the same behavior within a fixed budget of examples. Anything that cannot be transmitted this way is pruned on each generation cycle, and the surviving lessons become the next generation's training core (iterated cultural learning). The system adapts by changing what it teaches, not by refining a model of the world.
VALUE: Knowledge becomes explicit, portable and auditable by design, and opaque shortcuts that cannot be taught are removed systematically.

F53
MECHANISM: The system keeps a sparse set of frozen copies of its own weights from different points in its training history, chosen for maximal behavioural difference from each other. Before committing to an answer or an update, it asks a sample of these past selves to predict what the current self will say. It records where they diverge, and treats sudden divergence from all past selves at once as drift that needs justifying. An unjustified drift is rolled back for that input region, and a justified one is accepted and becomes a new council member.
VALUE: The system can notice and undo its own value or skill drift without an external grader.

F54
MECHANISM: Reasoning runs on a bijective (invertible-layer) network that keeps the full input-plus-scratch state rather than throwing information away. After producing an answer, the system runs the computation backward from the answer and its stated premises only, then measures how much of the original input it can reconstruct. Low reconstruction means the answer depended on something the premises do not contain, so the gap is surfaced as an unstated assumption. Training penalises those gaps, which pushes the model to make every load-bearing assumption explicit.
VALUE: Hidden assumptions become detectable as missing information rather than through confidence scores, so it becomes visible when a conclusion really depends on something unsaid.

F55
MECHANISM: Each acquired fact, rule or skill is logged with its parents, meaning the items it was derived or distilled from. This builds a sparse relationship matrix. Reliability is solved as a breeding value with Henderson's mixed-model equations, so an item with almost no direct checks borrows strength from its relatives. A single new check updates the whole family through A⁻¹.
VALUE: Reliability estimates for brand-new knowledge become usable after one or a few observations, because they draw on where that knowledge came from.
