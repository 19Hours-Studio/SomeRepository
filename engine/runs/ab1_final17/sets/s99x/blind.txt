F01
MECHANISM: All knowledge is stored as an atlas: local representation charts joined by learned transition maps (analogies, translations, unit and coordinate changes). Every inference is a transport along a path in this atlas. After each batch, the misclosures around all independent cycles are Hodge-decomposed. The gradient part is spread back over the edges by least-squares network adjustment. The curl part is pinned to a blundered edge by comparing cycles that pass through it with cycles that avoid it. The harmonic part becomes a new context variable with separate charts. Each edge's trust is the number of independent cycles that close through it, so redundancy stands in for a benchmark.
VALUE: The system keeps several frames that are each consistent but disagree with each other, such as jurisdictions, scientific paradigms or conventions. For any claim it can say whether a conflict is an error or a frame boundary, and which frame the claim belongs to. Researchers, translators and analysts who reconcile inconsistent sources would use it.

F02
MECHANISM: Every internal channel, and every sensor channel the agent reads from the world, carries a demodulating integrator. When the agent learns, it varies examples, non-examples or its own interventions according to a pseudo-random code that it controls. Orthogonal decoy codes that drove nothing are demodulated at the same time, giving a measured noise floor and false-lock rate. Channels locked above the floor are stored as a new concept unit together with its signal-to-noise ratio. The unit is re-tested with a fresh code and fading channels are dropped. Correctness rests on what the agent itself varied, so no judge is needed.
VALUE: An agent can learn a new concept or causal effect from a handful of noisy trials and report a calibrated false-detection rate for it. Lab automation, robotics and product experimentation would use it where trials are costly and confidence must be known.

F03
MECHANISM: The system presents a few examples of a concept and matched non-examples in an order set by a pseudo-random reference code that it controls, and per-channel integrators multiply each internal activation by the code and low-pass the product. Several orthogonal decoy codes that drove nothing are demodulated at the same time, giving a measured noise floor and false-lock rate. Only channels locked above that floor form the concept's address. The address is re-tested with a fresh code and fading channels are dropped, so correctness rests on a causal fact the system knows for certain (what it varied), not on its own judgement.
VALUE: Concepts can be isolated from very few noisy examples with a measured signal-to-noise ratio and false-detection rate, so the system knows how much to trust a concept it has just learned.

F04
MECHANISM: The system grows a pool of candidate input transformations by composing primitive edits (relabel, permute, reflect, rescale, swap roles). A candidate earns credit only if mapped-back answers agree under it more than they agree under random control edits of matched size, so a transformation that does nothing, or a model that ignores its input, earns no credit. Kept transformations must also close under composition: if T1 and T2 are kept, T1∘T2 must preserve answers too, and a failure of closure removes the weakest member. Answers that stay unchanged across the whole learned group become pseudo-labels for training and voting, and answers that break under it are flagged. The signal is the internal structure of the group, not verified cases.
VALUE: The system discovers for itself which changes to an input must not change the answer, and uses that structure both to check its own answers without an oracle and to generalize far outside its training distribution.

F05
MECHANISM: The system corrupts known-true items to create canary errors whose falsehood it knows by construction, and mixes them into its normal stream of claims. Two error-detection procedures with different mechanisms flag suspect claims. Their catch rates on canaries measure each procedure's recall. The overlap of their real-error catches, combined with that recall, gives a Lincoln-Petersen estimate of how many errors went undetected in each domain. The canary generator adapts its corruptions so that, statistically, canaries cannot be told apart from the real errors detected so far. Learning budget goes to domains whose estimated hidden-error mass is largest.
VALUE: The system can measure the errors it has not caught, using ground truth it planted itself, instead of trusting its own sense of being right.

F06
MECHANISM: The system is built from several generators that are decorrelated on purpose: different data shards, sources, tools and decompositions. Every belief it stores carries a capture history, meaning the set of generators that produced it. A latent-class log-linear model over these histories gives each belief a probability of being real rather than a phantom, and gives each query an estimate of how many relevant items remain unseen. Interaction terms that reveal a shared bias are used to train or recruit a new generator that is penalized for that dependence, and search stops when the estimated unseen and phantom shares both fall below a threshold.
VALUE: Without any oracle, the system can say both "I have found about 90% of what exists" and "about 5% of this list is probably spurious", and it knows when to stop. Systematic reviewers, auditors, due-diligence analysts and security teams would gain from this because completeness matters to them as much as accuracy.

F07
MECHANISM: Each reasoning step is generated by passing through stages that are the model's own re-encoding blocks. A step is discarded irreversibly with a probability that rises as its binding margin falls. The training signal is oracle-free: each step is paired with a sampled alternative that contradicts it, and the stages are trained to minimize how often both survive. That rate is a lower bound on the false-pass rate, so stages that fail together are pushed apart in training, not just swapped out. At inference the measured per-stage rate sets each step's cascade depth from a user-specified target error and from how much downstream work depends on that step.
VALUE: People running long proofs, plans or agent workflows get a reliability dial: they set a target error rate, and the system measures its own pass rates and spends compute only where the measurements say it is needed.

F08
MECHANISM: The system grows explicit transformation operators by composing primitive edits (relabel, permute, reflect, rescale, swap roles). An operator earns credit only if answers mapped back through it agree more than they do under random control edits of matched size. The kept set must stay closed under composition, and when closure fails the weakest member is removed. The learned group is not a test-time wrapper: inputs are encoded as an orbit-invariant core plus group coordinates. New problems are solved by mapping them into a canonical form, and answers that break the group are flagged and used as training signal.
VALUE: The system finds out for itself which changes to an input must not change the answer, and builds on that structure to generalize far outside its training data. It can also catch its own inconsistent answers. Scientists, engineers and people working on code or puzzles with hidden structure would gain from this.

F09
MECHANISM: A query is turned into a set of variables, which are partial answers and sub-goals, plus constraints between them that are learned or extracted from the query. Local update rules pass messages between these units, and the system keeps iterating until either a symbolic checker or a learned checker confirms that every constraint is met, or the energy of the system stops falling. When progress stalls, the system adds intermediate variables, for example lemmas or sub-plans, and stores successful arrangements as reusable templates.
VALUE: The system could spend compute in proportion to how hard a problem is and solve multi-step problems it cannot solve in one pass, with a clear signal for when it has succeeded and when it has failed.

F10
MECHANISM: Quantities carry integer dimension exponents, and Smith normal form over them yields the dimensionless groups. Every prediction is a learned function of those groups only. The correctness signal is cross-scale transfer on real data: a pi-law fitted on one magnitude band must predict observations in another band unchanged, because the world, not the model, supplies the variation in scale. If transfer fails while the in-band fit holds, the dimension assignment is wrong. SNF then adds a base dimension that separates the offending groups, and the scale test is re-run.
VALUE: The system can extrapolate far outside its training range, with a built-in falsification test whenever its notion of "same kind of quantity" is wrong.

F11
MECHANISM: Before every retrieval, calculator call, database query or sensor read made during ordinary work, the system hash-commits a probability distribution over the result. The returned value settles the wager immediately. Parametric weights are trained only on these settled log-scores, never on answers the system grades itself. Log-scores are also stored per topic and tool, giving a running, tamper-proof record of where its memory can be relied on. First test: Have Llama-3-8B commit distributions before 50k logged calculator and Wikidata lookups, then fine-tune on the settled log-scores; success means held-out tool-result log-loss drops at least 10% versus a self-graded fine-tune, and per-topic log-scores predict closed-book accuracy (Spearman > 0.6).
VALUE: Every action the system takes in the world becomes a correctness signal it cannot fake, so it gets millions of uncontaminated grades a day instead of waiting months for the future to arrive.

F12
MECHANISM: About 64 ensemble copies of a parameter subset take each new fact as an observation, with a gain built from parameter-prediction cross-covariance and a learned locality taper so that distant knowledge is untouched. Before a fact is assimilated, it is used as an honest forecast test: its innovation (observed minus ensemble-predicted) is compared against the ensemble spread plus that source's error variance. Desroziers-style innovation statistics, gathered over many facts, estimate each source's error variance online, so unreliable sources are down-weighted automatically, and a fact that fails the chi-square gate is quarantined instead of written in. The correctness signal therefore comes from prequential consistency between independent future observations and prior forecasts, not from the model judging itself.
VALUE: The system can keep absorbing streams of facts and corrections from sources of unknown reliability, learning how far to trust each one, without retraining and without forgetting.

F13
MECHANISM: Each reasoning step is scored under several re-encodings of its context, drawn from different kinds of source (paraphrase, formal translation, a different model, a tool run). The margins are treated as edge flows on the graph of encodings and given a Hodge decomposition. The gradient part is a per-encoder bias, estimated across all steps and subtracted. The curl part is inconsistency, and the step is discarded. The harmonic part becomes a local chart with an explicit context variable. The decomposition is trusted only if, after fitting on k encodings, it predicts the step's margin on a new encoding before that encoding is scored. That held-out prediction is the correctness signal, so neither a biased encoder nor an overfit chart can certify itself. A chart whose transition maps keep mispredicting new encodings is dissolved.
VALUE: Long reasoning becomes more reliable without throwing away conclusions that hold only in some contexts, and the system learns where its knowledge splits into separate frames.

F14
MECHANISM: Concepts are stored as nodes in a lineage network rather than as points in one embedding space, and properties are inherited along weighted edges. Every structural edit (a new branch, a re-parenting, or a two-parent reticulation) is tested in several distance metrics, each built from independent evidence: co-occurrence, shared properties, form or etymology, perception. An edit is accepted only if every metric shows the same four-point-condition violation and yields the same admixture weight. An artifact of one embedding fails this check because it shows up in only one metric. The weights are re-solved as evidence arrives, and nodes whose weights drift apart across metrics are demoted.
VALUE: Chemists, biologists, linguists and product analysts get a model that reasons about inheritance and blends (hybrid species, loanwords, new compounds, fusion categories), can say which parent each belief came from, and can tell real hybrids from artifacts of its own embeddings without a labeled oracle.

F15
MECHANISM: Every internal quantity carries an integer exponent vector over learned base kinds. Multiplication adds the vectors, and addition or comparison requires them to match, so an imbalance is computed by exact integer arithmetic, not by a learned judge. The model only proposes kind assignments. These are scored against expressions people actually write in corpora, tables and spreadsheets (external data the model did not produce), and the score maximizes the number of syntactically possible combinations the kind system forbids while keeping zero imbalance on observed expressions. This stops the trivial "everything is one kind" solution. A persistent imbalance creates a new kind or a conversion constant, and a kind that forbids nothing is merged away.
VALUE: Nonsensical reasoning steps are rejected by an exact check that the fallible model cannot argue its way around, and magnitudes extrapolate through scaling rules.

F16
MECHANISM: When prediction error on an input crosses a learned threshold, the system writes a small key-value module next to the frozen core. The key is the context embedding and the value is a low-rank change to the core's weights. Those changes take effect only when a later context is similar to that key. During an offline phase, the system replays old episodes against the patches. It merges patches that do the same thing and deletes ones that conflict, using how often they agree as the score. Each patch keeps a count of how often it was used and how often it was confirmed, and patches that stop earning their place are removed.
VALUE: The system could learn permanently from a single experience without forgetting what it already knows or needing retraining.

F17
MECHANISM: One model answers each question at a shallow and at a deep compute budget. Each run also predicts the distribution of answers the other run will give. An answer is credited when it is more common than the cross-predictions expected, and deep chains are rewarded when they correctly predict the shallow answers while the shallow runs fail to predict them. This Bayesian-Truth-Serum score is the reward for revising weights. The system stores per-domain asymmetry statistics and stops training wherever the asymmetry disappears. First test: Run Qwen2.5-7B on 1,000 MATH problems at 64- and 1024-token budgets, with cross-predicted answer distributions, and no training; success means the BTS score's AUROC for ground-truth correctness beats self-consistency majority-vote confidence by at least 0.05.
VALUE: It gives a correctness reward without an oracle, based on an information asymmetry that the model cannot fake by agreeing with itself.

F18
MECHANISM: For cues that compete over an internal feature, the system titrates one cue against increasing amounts of the other and fits a Schild slope to the dose-ratio shifts. It also checks the pharmacological null-method invariant: a true single site gives the same antagonist affinity (pA2) whatever agonist cue is used. A slope away from 1, or a pA2 that depends on the agonist, triggers a split into gated sub-sites. The split is kept only if each new sub-site then passes both tests itself, so a mathematical invariant of the model's own activations grades the repair, not a fallible judge.
VALUE: Features that are secretly several mechanisms are found and separated, and the result is checked by a quantitative law, so the model's internals become more faithful and reasoning that combines cues becomes more reliable.

F19
MECHANISM: A problem is decomposed in two deliberately different orders (an interleaver). This produces two reasoning chains whose intermediate claims are scored as log-likelihood ratios against parity-like constraints (units, conservation laws, cited values). On each pass, a chain subtracts the belief it received from the other chain before sending its own update. Only extrinsic evidence crosses over, so neither chain counts its own conclusions twice. Mutual-information transfer (EXIT) curves are stored per problem type. They predict whether the exchange will converge, and when it will not, the answer is withheld and the system goes looking for more constraints.
VALUE: Long reasoning chains can correct each other without an echo chamber, and the system can tell beforehand when internal checking cannot reach a reliable answer.

F20
MECHANISM: The model is a population of sub-models, and each new fact is held by a random half of them. Every ordinary prediction is therefore also a controlled trial for every fact that is still in admission. A fact's binding margin is how much better its holders predict incoming observations than its non-holders, scored before those observations are absorbed and accumulated over all routine predictions. The trial grows with how much of the model the fact would change. A fact is dropped as soon as its margin is reliably negative, and it is fully admitted once its accumulated margin crosses a sequential-test bound.
VALUE: A deployed system can keep learning from untrusted streams (web text, user corrections, reports) and admit only claims that make it better at predicting what actually happens next, with a causal credit attached to each fact. Assistants and monitoring systems that must update continuously without being poisoned would gain from it.

F21
MECHANISM: Three or more predictor lineages are trained on disjoint evidence channels about the same events, such as text reports, numeric logs and imagery. The channels are chosen so that their errors are conditionally independent. From the pairwise and three-way rates at which the lineages agree, a latent-class (Dawid-Skene-style) estimator recovers each lineage's accuracy per region without any labels. The system trains only on events where the triangulated posterior is confident. It runs higher-order agreement tests to detect when independence has broken down and then splits or reroutes channels.
VALUE: It gives label-free, mathematically identifiable accuracy estimates in open domains, derived from how independent views agree rather than from any one model judging itself.

F22
MECHANISM: A bank of coupled phase oscillators runs continuously, timestamped events phase-reset or nudge it, and each oscillator adapts its natural frequency to reduce phase error at event onsets. Expectations are read out as the phase at which the next event should arrive. A phase-locking pattern is consolidated as a concept or routine only if its onset predictions on future events beat the same bank driven by jittered surrogate streams. The correctness signal is the actual arrival time of the next event, which the world supplies with no judge.
VALUE: The system gets a real sense of duration, rhythm, deadlines and "something is late", and can discover hidden periodicities in event streams, which clockless token-sequence models cannot do.

F23
MECHANISM: The system injects graded perturbations into live tasks, and the correct effect of each one is known by construction: inserted facts with fixed consequences, unit rescalings, swapped entities, planted sub-results. It fits a line of output shift against spike size. The slope gives recovery for that input type, and extrapolating the line to zero spike gives a bias-corrected answer. Input types with low or uneven recovery get their own adapter modules, and an adapter is deleted if recovery does not improve. The system only grades known differences, never its own absolute answers.
VALUE: Context-specific distortions are measured and corrected on real inputs where no answer key exists.

F24
MECHANISM: Every claim the system derives becomes a station in one persistent network that is kept across all queries. A least-squares adjustment with Baarda's w-test finds the faulty step in any loop that fails to close. The adjustment carries a covariance between routes, estimated from shared premises, sub-steps and tools, so routes produced by the same model cannot certify each other just by agreeing. From this the system computes each claim's minimal detectable bias: the largest error that could still be hiding in it. Answering is gated on that bound. When it is too large, the planner adds a route to a control station, meaning a value fixed outside the model (a measurement, an executed computation, a cited source). It picks the control that most reduces the total minimal detectable bias across the whole network, so each scarce external check tightens many stored claims at once.
VALUE: Engineers, analysts and researchers get a knowledge base that states, for every claim, how large an undetected error could be, and that spends scarce real-world verification where it tightens the most claims.

F25
MECHANISM: Many heterogeneous modules (search, simulation, symbolic solvers, small neural nets) bid for slices of a shared compute budget. A bid is priced by the expected reduction in task uncertainty, and the payout is the realized reduction. Modules that bid well gain budget and get copied with mutations, while chronically bad bidders are retired. The architecture is therefore an evolving economy rather than a fixed graph.
VALUE: It makes possible adaptive, open-ended allocation of reasoning effort and self-directed architectural growth after deployment.

F26
MECHANISM: An embedding-indexed map stores the system's ground-truth-verified error statistics for each region of problem space, updated whenever an outcome is checked. Before answering, the system looks up the query's region. It then answers, abstains, asks for information, or routes the region to the learning loop, depending on the measured reliability and the cost of being wrong.
VALUE: It gives reliable self-knowledge of where the system is competent, so it can abstain and direct its own learning based on its actual track record.

F27
MECHANISM: Surprising experiences go verbatim into a fast episodic buffer. During offline phases the system replays them to propose weight deltas inside a sandboxed copy of its slow network. Each delta is accepted only if a self-maintained regression suite of past skills shows no loss, and rejected deltas are stored as interference records that shape later proposals.
VALUE: It enables continual lifelong learning after deployment without catastrophic forgetting.

F28
MECHANISM: The model's beliefs act as a background state. Each new datum from a document, user, instrument or tool is an observation, and the system computes the innovation (observation minus prediction) and the analysis residual. Desroziers consistency identities over these statistics give separate estimates of the model's error covariance and of each source's error covariance, so no labels are needed. These estimates set the gain that decides how much each observation changes the stored beliefs and parameters. A source whose estimated error grows is down-weighted automatically, and so is a model region whose estimated error grows.
VALUE: The system learns continuously from noisy, adversarial real-world streams while measuring its own reliability and each source's reliability from the data alone.

F29
MECHANISM: All post-deployment learning works the same way. Whenever new data's gradient conflicts with a module's frozen probe signature, the module splits into two twins with complementary sparse masks, so that only the pair together reproduces the old signature. Neither twin can win by rewriting past behavior. Wherever the twins disagree, each places a bet before the outcome is known, and the world settles it later: the next item in a stream, a tool result, the user's next turn, a later document. Such outcomes arrive constantly during ordinary use. A twin's sub-functions are pruned only after it loses bets it placed itself. A pair whose winner is clear collapses into a single module, keeping the parameter count bounded.
VALUE: Deployed assistants and agents keep learning new skills from their own use without forgetting old ones. Every update is checked against outcomes the world later produced, never against the model's own grading.

F30
MECHANISM: Small parameter lesions that change a behavior are paired and "crossed" by mixing activations between the two lesioned copies. Restoration means separate functional units and no restoration means the same unit, and the resulting groups re-partition and re-route the parameters. The reference phenotype is the intact model's own output, not a correct answer, so module discovery needs no oracle. A proposed fix for an externally flagged failure is accepted only if it complements the lesions of exactly one group and leaves behavior on the other groups' probes unchanged. The anchor cannot say what counts as a failure (that one flag stays external), but it makes localization and side-effect checking oracle-free.
VALUE: The system's module structure comes from functional evidence, so fixes, transfer and growth stay local and their side effects can be verified.

F31
MECHANISM: Claims are nodes and derivations are transformation edges. A Hodge decomposition splits the misclosure of every loop into three parts: a curl part (local, so the faulty step can be found with a w-test), a harmonic part (global, so it is either a mistake or a real frame split), and a gradient part (systematic offsets that no loop can see). The harmonic part gets bridging derivations, each chosen by minimal-detectable-bias and taken from a different source than the loop it crosses (tool, retrieval, model). If the misclosure collapses, it was a mistake. If it survives every bridge, a context variable splits the frames. The crux is handled by the decomposition itself: the gradient subspace is exactly what the system cannot grade by itself, so the system never trusts it and spends external observations ("control points") only on the nodes that span it.
VALUE: The system can find and classify its own reasoning errors with no oracle, and it can say exactly which beliefs only outside evidence can check.

F32
MECHANISM: Every activation that stands for a quantity or entity carries an integer exponent vector over learned base kinds, and the network's composition operations are typed. Multiplication adds the vectors. Addition, comparison and attention between values are masked unless the vectors match, so an ill-kinded combination is impossible inside the computation rather than caught afterwards. The kind lexicon is fitted to expressions people actually write in corpora, tables and spreadsheets, which are external data the model did not produce. Its objective is to forbid as many syntactically possible combinations as it can while keeping zero imbalance on observed expressions. A persistent imbalance adds a new kind or a conversion constant, and a kind that forbids nothing is merged away. Kinds are not limited to physics: currencies, per-capita versus totals, people versus households, and dates versus durations all become learned base kinds.
VALUE: Analysts in finance, policy, science and engineering get quantitative reasoning in which whole classes of category errors are impossible by construction rather than something the model has to notice, and magnitudes extrapolate through exact scaling rules.

F33
MECHANISM: Knowledge-bearing weights are stored as a mean plus about 64 low-rank anomaly directions, so the ensemble is cheap. Assimilation replaces fine-tuning as the way new facts get in: the gain comes from parameter-prediction cross-covariance with a learned locality taper. Before a fact is written in, its innovation is gated against ensemble spread plus the source's error variance. Desroziers statistics over many facts estimate each source's error variance and the cross-source error covariance, so correlated sources are not double-counted. Facts that fail the chi-square gate are quarantined. The ensemble spread at inference gives calibrated uncertainty on every answer.
VALUE: Newsrooms, clinical-guideline systems and intelligence desks get a model that absorbs live feeds and corrections every day without retraining or forgetting, learns how far to trust each source, and says how sure it is.

F34
MECHANISM: The world model's state is a bar framework: entities are points and observed interactions are bars, and generation and prediction read from it. A quantity counts as conserved exactly when its observed transfers lie in the framework's equilibrium-stress space, which linear algebra checks without the model's judgment. A persistent imbalance is treated as a load, and a hidden entity is placed where floppy modes can carry it. Maxwell counting then fixes how many new bars it needs and to which entities, which predicts specific interactions that have not yet been observed. The entity is kept only if later observations fall on those predicted bars and the dimension of the stress space changes as counted. Where the predicted stresses conflict, the entity splits in two.
VALUE: Investigators, auditors and biologists get exact state tracking over money flows, supply chains or signaling networks. The system also locates unseen actors and predicts their connections in a way later observations can confirm or refute.

F35
MECHANISM: For each claim, the system makes two small weight edits: one that asserts the claim and one that asserts its negation. It then measures how well each edited model predicts a held-out stream of raw data (documents, logs, sensor records) that was not used for the edit. The difference in log-likelihood, compared against a null distribution from edits of random claims, is stored as the claim's support. Claims the world prefers are consolidated, and claims whose negation predicts better are retracted. Claims that sit inside the null band are labelled "uncontrolled by any data" rather than trusted. First test: Apply ROME assert/negate edits to GPT-2 XL for 300 CounterFact claims and score held-out Wikipedia paragraphs about each subject against a random-claim null; success means the sign matches truth for more than 75% of claims, and null-band claims are mostly those whose subjects lack held-out text.
VALUE: Unlabeled raw data, not the model's opinion, decides whether each belief is right, wrong or unverifiable.

F36
MECHANISM: A small rule set, checked once by hand, holds transformations whose effect on the correct answer is fixed by construction. Examples: swapping units should rescale a number, reordering items should leave a count unchanged, duplicating a list should double a sum, and negating a premise should flip a conclusion. The system answers both the original question and its transformed version. Any answer pair that breaks the known relationship is certainly wrong, whatever the true answer is. The violation rate is stored for each pair of topic and transformation, and the parameters are pushed toward restoring the relationship. Topics with high violation rates get the most new transformations.
VALUE: The system finds certain errors on questions nobody knows the answer to, because the error signal comes from fixed algebra rather than from the model's opinion.

F37
MECHANISM: Every assertion the system adopts becomes a node in a persistent graph that stores its source, confidence and the nodes it was derived from. On each inference step a constraint checker scans for contradictions. Conflicts are resolved by retracting the least-supported justification, and the retraction automatically propagates to all dependent conclusions (truth maintenance). Generation is restricted to drawing on the active ledger and has to cite node IDs.
VALUE: It enables lifelong learning without catastrophic forgetting, with traceable reasoning and instant correction of any fact and everything derived from it.

F38
MECHANISM: The network learns its own module boundaries during training. Pairs of small lesions that change a behavior are "crossed" by mixing activations between the two lesioned copies. If the behavior comes back, the lesions hit separate units; if it does not, they hit the same unit. The resulting complementation groups become the network's routing partition, and it is re-partitioned periodically. Every later update, such as a gradient from a user correction or a task outcome, is confined to the parameters of exactly one group and is committed only if it fixes the flagged behavior while every other group's probe phenotype stays unchanged. That phenotype is measured against the intact model's own outputs, so no oracle is needed. The failure flag itself stays external and can be sparse. Localization, containment and side-effect verification are things the architecture computes for itself.
VALUE: Teams that run continually updated models can apply each correction from sparse real-world feedback as a local edit whose lack of side effects is verified, so the model can keep learning for years without regressions or retraining.

F39
MECHANISM: Concepts are embedding points. Each fact is a learned constraint function on them, not only a distance, and the generalized rigidity matrix (the Jacobian of all constraints) is maintained incrementally by sparse factorization as the model's knowledge store. Floppy modes trigger a query along exactly that direction, and an answer is accepted only if it removes the mode without adding stress. Self-stress is counted as evidence only among constraints from independent sources, so constraints the model generated itself can never cross-check each other. Concentrated stress retracts a fact, and stress that splits into two rigid, stress-free blocks splits the concept in two.
VALUE: Knowledge-base builders, tutors and research agents get a model that asks the one question that pins down an ambiguous concept, and can show which facts are cross-checked and which are not.

F40
MECHANISM: Each candidate step passes n stages of increasingly decorrelated re-encoding, and it is discarded irreversibly with a probability that rises as its binding margin falls. The true per-stage false-pass rate is measured without an oracle by also pushing mutually exclusive step pairs through the cascade (the step and a sampled contradicting alternative). At most one of each pair can be true, so the fraction where both survive gives a lower bound on false-pass. Comparing that fraction stage by stage exposes correlated stages, which are replaced with more distant re-encodings. n is then set from the measured rate, not the assumed ε^n, and scaled by how much downstream work depends on the step.
VALUE: Long reasoning chains get a calibrated, self-measured reliability dial instead of compounding errors or overconfident self-verification.

F41
MECHANISM: Every conservation identity in a narrative ledger becomes a condition equation in a least-squares adjustment. Baarda w-tests then decide between "blunder at step k" (a local residual) and "hidden holder h" (a shared pattern across loops), and a holder is admitted only if it passes significance and lowers other claims' minimal detectable bias. The conservation identities act as the oracle because they are structural, not judged by the model. Variance-component estimation learns per quantity how strictly conservation actually holds. Redundancy numbers mark the claims that no identity checks, and only for those does the planner request or derive one extra external count.
VALUE: The system can track world state over very long texts, saying which step is wrong or which unmentioned participant must exist, with a confidence for each verdict and an explicit list of what it cannot check.

F42
MECHANISM: Every quantity or claim the system asserts is computed along several derivation paths that share no sources, linked by arithmetic, unit and accounting identities. Weighted least squares adjusts the estimates so the identities hold, a chi-square test checks how far they fail to close, and a per-path test isolates the path most likely to carry a gross error. That path is retired, given a learned bias term, or split by context where its errors cluster. Agreement between independent paths under fixed identities is the correctness signal, so no oracle or self-judgment is needed.
VALUE: Faulty knowledge sources can be found and repaired in open domains without ground truth.

F43
MECHANISM: The system maintains a population of small probabilistic programs, each a candidate simulator of some part of the environment. Queries are answered by running or intervening on the best-scoring simulators. Prediction errors drive program-synthesis mutations, and simulators are selected by how well they compress observations and predict accurately.
VALUE: It gives explicit causal and counterfactual reasoning and lets the system discover new models that can be inspected.

F44
MECHANISM: In the background, the system copies verified source values (numbers, relations, entities) into its belief store and corrupts them by graded known amounts. It then measures what fraction of each corruption its next inferences pull back toward what neighbouring beliefs imply. This restoring-force slope is stored for each region of the belief store. A slope near zero marks the region as uncheckable. A real belief that deviates from its neighbour-implied value by more than the measured slope allows is flagged as a likely blunder and revised. Regions whose slope drops trigger targeted relearning, and the slope is measured again afterwards. First test: Load Wikidata country statistics, which are linked by identities such as GDP/population, plant graded corruptions, and fit per-region restoring slopes; success means slope-thresholded flagging catches separately planted unknown blunders with precision > 0.8 in high-slope regions and near chance in low-slope regions.
VALUE: Without an oracle or self-grading, the system can tell which of its beliefs are actually held in check by other knowledge, and can find specific errors there using only errors it planted with known size.

F45
MECHANISM: The system logs its surprise (log-loss) on every incoming datum, tagged by source and knowledge region. It continuously regresses each region's later surprise on earlier surprises from each source. A positive lagged correlation means that source was under-weighted; a negative one, where the model was misled and corrected later, means it was over-weighted. These coefficients directly set the per-source trust weights and per-region learning rates, which are adjusted until the surprise sequences become unpredictable. First test: Train an online small LM on a synthetic multi-source stream with known per-source noise and bias, then apply lagged surprise-regression trust; success means learned trust weights rank true source reliability (Spearman > 0.8) and final held-out loss beats uniform weighting.
VALUE: The system learns continuously from untrusted streams and calibrates its own plasticity and each source's reliability from the stream alone, with no labels.

F46
MECHANISM: The system keeps a growing library of input transformations, each paired with a relation its outputs must provably satisfy: unit changes rescale answers, irrelevant permutations leave them unchanged, and counterfactual edits move them in a known direction. Each answer is re-asked under these transformations, and violations of the relations are the training loss. New relations are kept only if they are derivable a priori, for example from symmetry, dimensional analysis or the structure of the edit.
VALUE: It detects and corrects errors without ever knowing the true answer, as metamorphic testing does for programs that have no test oracle.

F47
MECHANISM: Every layer is a bijection, and every bit a step would discard is written to an ancilla tape, so the network can run backward exactly. To check an output, the system fixes both the actual input and the output and runs backward. The number of ancilla bits that must be invented to reconcile the two is an exact bit count of how much of the output the input does not support, not the model's opinion of it. Zero invented bits means the output follows from its evidence, a high count means it was fabricated, and that count is the training signal. One example's influence is removed by uncomputing its trace. The audit separates grounded content from invented content, but it does not certify that the input itself is true.
VALUE: The system gets exact provenance, a measured count of unsupported information in every claim, exact counterfactual inputs and certified forgetting, none of which an LLM can provide because it discards information at every layer.

F48
MECHANISM: Each intermediate claim is a station derived along several routes. A least-squares adjustment with Baarda's w-test finds the faulty step in any loop that fails to close. Routes produced by the same model can share an error and still close perfectly, so the adjustment carries a covariance between routes, estimated from shared premises, sub-steps and tools. From that it computes, for every claim, its minimal detectable bias: the largest error that could still hide in that claim given those correlations. A claim whose minimal detectable bias is too large is not answered until the planner adds a new route to a control station, meaning a value fixed outside the model (a measurement, an executed computation, a cited source), just as a survey is anchored to fixed benchmarks.
VALUE: Long reasoning chains find their own faulty step and state, for each conclusion, how large an error could still be undetected, instead of mistaking self-agreement for verification.

F49
MECHANISM: Several retrieval or generation passes, built to fail in different ways (different sources, cues and decompositions), each "capture" candidate items, and every item gets a capture history: the set of passes that found it. A latent-class log-linear capture-recapture model fitted to these histories does two things. It estimates how many real items are still unseen, and it separates real items, which independent passes recapture, from phantoms, which stay confined to one pass or one correlated group of passes. The pass-interaction terms show where passes share a bias, and the system then adds a pass that breaks that dependence. Sampling stops when both the estimated unseen share and the estimated phantom share fall below a threshold.
VALUE: Without any oracle, the system can say both "I have probably found 90% of the relevant items" and "about 5% of what I listed is probably spurious", and it knows when to stop searching.

F50
MECHANISM: Concepts are points and facts are geometric constraints, and the system continuously computes the framework's rigidity matrix. Its null space (floppy modes) marks underdetermined concepts, which trigger a query along exactly that direction, and an answer is accepted only if it removes the mode without creating stress. A state of self-stress is the oracle-free error signal. If the stress concentrates on one constraint, that fact is retracted. If it splits the constraints into two groups that are each rigid and stress-free, the concept is split in two. Facts in redundant, stress-free regions are trusted because they are cross-checked; facts in floppy regions are explicitly unverified.
VALUE: From geometry alone, the system can tell where its knowledge is wrong, ambiguous or unverified, and repair each case structurally.

F51
MECHANISM: The system turns each belief into a falsifiable prediction about future raw data streams, such as sensor feeds, registries, prices or archives. It hash-commits the prediction together with a resolver: a small, deterministic parsing predicate frozen at commit time. Weights may learn only from predictions that have matured, and each one is scored by its frozen resolver against data that did not exist when the model made the claim. The escrow ledger stores calibration per domain and per horizon, and resolvers that drift or turn out ambiguous are retired.
VALUE: The current model cannot shape its own grade, because the world settles the score later through a judge fixed before the outcome existed.

F52
MECHANISM: The system's memory stores beliefs as edge quantities, meaning derivations that relate claims. Node beliefs are read out as the least-squares potentials of that graph, and a Hodge decomposition runs on it continuously as part of inference. The curl part of each loop's misclosure points to the faulty derivation (found with a w-test). The harmonic part triggers a bridging derivation chosen by minimal detectable bias and taken from a source different from the loop it crosses: if the misclosure collapses it was a mistake, and if it survives it marks a real frame split, which adds a context variable. The gradient subspace is exactly what the system cannot grade itself, so it is never trusted internally, and external observations ("control points") are spent only on the nodes that span it.
VALUE: Researchers, auditors and intelligence analysts get an AI whose belief state separates internally verified conclusions from genuine frame disagreements, and gives the smallest set of outside observations needed to anchor the rest.

F53
MECHANISM: The network's units are binding sites rather than neurons. Each input cue has a learned affinity and efficacy at each site, and a site's output is its occupancy computed from a fixed competitive-binding law, so the response to any mixture of cues has a closed form. While learning, the system titrates cues against each other on its own sites. If the Schild slope is not 1, or the pA2 changes depending on which agonist cue is used, the site is split into gated sub-sites. The split is kept only if each child passes both tests and predicts observed outcomes for cue mixtures it was not fitted on, so the repair is graded by a mathematical invariant plus held-out world data, not by a judge.
VALUE: The system can predict how evidence, interventions or factors combine in mixtures it has never seen, such as drug combinations, multi-symptom diagnosis or multi-factor risk, because combination follows a validated law and is not memorized. Clinicians, pharmacologists and analysts who must weigh many interacting signals at once would use it.

F54
MECHANISM: Perception updates a running graph of objects, their attributes and typed causal links. Each link carries a probability and a count of how many times its predictions came true. Before each step the system simulates what it expects to observe, then compares that with what it actually observes. When they differ, it traces the error back through the graph to the links most to blame and revises them: it adds hidden variables, splits links or reverses their direction. It can also run interventions inside the graph to test competing explanations before acting.
VALUE: The system could know when its beliefs are wrong, reason about counterfactuals, and keep a consistent, inspectable model of the world over long periods.

F55
MECHANISM: A new fact waits in a queue. At each stage, one disjoint subset of ensemble members provisionally absorbs it (treatment) and a matched subset does not (control). The fact's binding margin is how much better the treatment subset predicts the facts that arrive in the stream during the delay, measured before those facts are absorbed. The number of stages grows with how much of the model the fact would change, a fact with a negative margin at any stage is gone for good, and survivors are weighted by their accumulated margin. The world's later data, not the ensemble's opinion, grades each fact.
VALUE: The system can keep learning from a stream of claims and admit only those that make it better at predicting what it encounters next, so wrong facts that would cause broad damage are stopped before they get in.

F56
MECHANISM: Whenever the system makes a claim, it also writes down concrete, checkable predictions about data that has not arrived yet: future entries in incoming streams, logs, measurements or published records that the system cannot write to. Each prediction is stored with a fingerprint and a deadline so it cannot be changed afterwards. When the data arrives, a fixed string or number comparison settles the prediction mechanically. Only settled predictions change the parameters, and each update is weighted by how surprising the outcome was. The claims that produced wrong forecasts lose influence on future answers.
VALUE: The system can correct itself in open-ended domains with no oracle, because the world's future acts as the grader and that grader cannot be flattered or influenced.

F57
MECHANISM: For any numeric inputs, including tabular or sensor data with no units, the model learns integer dimension assignments. Smith normal form turns them into dimensionless groups, and the predictor can see only those groups. The training signal is cross-scale transfer on real data: a law fitted on one magnitude band must predict another band unchanged, because the world, not the model, supplies the variation in scale. If transfer fails while the in-band fit holds, SNF adds a base dimension that separates the offending groups, and the test is run again. The dimensional structure is therefore discovered from the data and keeps getting falsified by it, rather than being given by hand.
VALUE: Engineers and scientists scaling from lab to plant, or from simulation to field, get models that extrapolate far outside the training range and report when their notion of "same kind of quantity" has broken.

F58
MECHANISM: Holders are points and transfers are bars between them. A quantity counts as conserved exactly when its observed transfers lie in the framework's equilibrium-stress space, which linear algebra checks without the model's judgment. A persistent imbalance is treated as a load. A hidden holder is placed where the floppy modes can carry that load, and Maxwell counting then fixes how many new bars it must have and to which holders, which predicts transfers not yet observed. The holder is kept only if later transfers fall on those predicted bars and the dimension of the stress space changes as counted. Where the predicted stresses conflict, the holder splits in two.
VALUE: The system can keep exact track of world state and locate unseen participants, with their existence and connections derived from the framework's geometry and confirmed by later observations.

F59
MECHANISM: A bank of coupled oscillators that adapt their frequencies is the agent's clock and its memory index. Every event and memory is stored under the phase vector that was current when it happened, retrieval works by phase similarity, and actions are scheduled as target phases. Oscillators adapt to reduce the phase error at the moment each event arrives. A phase-locking pattern is consolidated into a routine or concept only if its predicted arrival times beat the same bank driven by jittered surrogate streams. The correctness signal is the actual arrival time of the next event.
VALUE: Long-running agents get a real sense of duration, rhythm and lateness. They can notice that something is overdue, find hidden periodicities and anticipate what comes next. Operations teams, care monitoring and logistics would use it to watch event streams that never stop.

F60
MECHANISM: Several critics trained on disjoint views of the data flag suspected errors in the system's outputs. A latent-class capture-recapture model fits the overlaps between their flags and estimates each critic's false-flag rate, how strongly the critics depend on each other, and how many errors went uncaught in each input region. Where the estimated uncaught errors are high, the system trains a new critic on a fresh disjoint view. Where critics have become too similar, it retrains one of them to make them independent again, and it deletes critics whose catches the others already cover.
VALUE: The system can measure what it fails to notice and grow detectors exactly there, without an oracle.

F61
MECHANISM: Learned maps (analogies, translations, coordinate transforms) are composed around every independent cycle, and the misclosures are Hodge-decomposed. The gradient part is spread back over edges by least-squares network adjustment. The curl part is pinned to specific edges by a redundancy blunder test: an edge is condemned when the cycles that pass through it disagree with the cycles that avoid it. The harmonic part, which no local edit can remove, is treated as a real topological hole and gets a new context variable with separate charts and transition maps. Correctness comes from redundancy alone: a map is trusted in proportion to how many independent cycles close through it, as in surveying without a known benchmark.
VALUE: The system can find out on its own whether a contradiction in its knowledge is an error to delete or a sign that it needs several context-dependent frames, and it builds those frames instead of averaging contradictory regularities into one incoherent map.

F62
MECHANISM: The model's working memory is a ledger of quantities: objects, money, people, stock and allocated resources. Every conservation identity it implies is a condition equation, and the model reads state only from the least-squares-adjusted ledger, never from raw recall. Baarda w-tests separate "blunder at step k" (a local residual) from "hidden holder h" (a pattern shared across loops). A holder is admitted only if it is significant and lowers other claims' minimal detectable bias. Variance-component estimation learns how strictly each identity holds. The identities are structural rather than judged by the model, and redundancy numbers mark every unchecked claim, for which the agent requests one external count.
VALUE: Agents doing long-horizon bookkeeping, logistics, case files or multi-day tasks keep a state that stays consistent and can name the wrong step or the missing participant, with a confidence for each verdict and a list of what it cannot check.

F63
MECHANISM: Every quantitative or relational claim the system holds is treated as a surveyed observation with a variance, and it is linked to independent observations (retrieved sources, tool outputs, sensor readings) through closed constraint loops. Weighted least-squares adjustment spreads each loop's misclosure across its claims. Baarda's normalized-residual test then names the specific claim that is most likely a blunder, which gets revised or discarded. For each claim the system stores a redundancy number that says how far other observations control it. Claims with near-zero redundancy are marked as structurally unverifiable rather than as trusted.
VALUE: The system can locate and fix its own errors, and knows which beliefs nothing can currently check, without an oracle or a self-grading model.

F64
MECHANISM: The system keeps snapshot copies of itself, each trained only on data before a strict cutoff date, and asks them questions that the archive settled after that date. The archive grades their answers with no model judgment involved. The system stores which reasoning strategies and update rules improved these later-verified answers and transfers only those to the present model. Contamination audits drop any snapshot whose training data leaked material from after its cutoff.
VALUE: It turns the passage of time into an oracle for open-ended domains, so improvement is graded by the world rather than by the model itself.

F65
MECHANISM: Every stored belief keeps its provenance: sources, intermediate derivations and earlier model states. The system builds a genealogy tree in which beliefs that share rare, idiosyncratic errors are joined as descendants of a common ancestor. A claim counts as corroborated only when it appears in branches that the tree shows to be independent; support from copies of one ancestor counts once. When an ancestor node is found to be corrupt, the system retracts or down-weights the whole subtree it fed. First test: On the Dong et al. truth-discovery datasets (Stock and Flight, which have known copier relations), build error-sharing genealogies and count only independent branches; success means truth-selection accuracy beats naive voting by at least 10 points and matches or beats ACCU/copy-aware baselines.
VALUE: It can learn continually from a web of mutually copying sources without mistaking repetition for evidence.

F66
MECHANISM: When the gradient from new data conflicts with a module's frozen probe signature, the module splits into two twins. The twins get complementary sparse masks, so only the pair together reproduces the old signature, and the system judges between them only by which one better predicted the world's next observation. Because the pair holds the old signature by construction, neither twin can win by rewriting past behavior. They compete only on inputs where they disagree, and each disagreement is held as an open bet until the delayed outcome arrives (the next item in a stream, the result of an action, a later document). A twin's own sub-functions are pruned only after it loses bets it placed itself, so the correctness signal is always a prediction made before the outcome, never a judgment made afterward.
VALUE: The system keeps learning new skills after deployment, with old skills preserved in its structure and new ones checked against what the world later shows, not by grading itself.

F67
MECHANISM: Every state change is posted as a debit from one holder and a credit to another, across a learned set of conserved quantities. Any nonzero sum after a step is the error signal, and it needs no oracle because balance is an algebraic invariant, not a judgment. To stop the system from balancing its books by invention, a hidden holder created to absorb a persistent imbalance must be issued as a forecast of which future transfers it will settle. It is removed if those transfers never arrive or if a total stated in the input (a count, a balance, a census) contradicts it. A quantity is dropped from the conserved set when stated totals for it repeatedly fail to reconcile.
VALUE: The system can track world state exactly over very long sequences and infer unmentioned participants or leaks, and later input can disprove each such inference.

F68
MECHANISM: Each claim or explanation the system produces is given to a small, freshly initialized student model. The claim is scored by how much it improves the student's prediction of held-out raw observations from the domain, compared with a student that did not receive it. The system stores these gains per claim and trains itself toward claims with high gains, while claims with no gain are demoted.
VALUE: It grounds correctness in abundant unlabeled data, which exists everywhere, instead of in the system's own fallible judgment.

F69
MECHANISM: The model's working memory is a ledger. It holds accounts for every participant over a learned set of conserved quantities such as money, objects, permissions, obligations and who-knows-what. Each step the model takes must be written as a balanced debit and credit, and generation reads its state only from these balances, never from free-floating activations. The posting rule is part of the architecture, so a nonzero sum is a built-in training loss that needs no oracle, because balance is algebra and not a judgment. When an imbalance persists, the system creates a hidden holder, but only as a forecast of which future transfers will settle it. If those transfers never arrive, or if a total stated in the input (a count, a balance, a census) contradicts the holder, it is deleted. A quantity is dropped from the conserved set when stated totals for it keep failing to reconcile.
VALUE: Agents, auditors and analysts get a system that keeps exact world state across very long documents, transactions or action sequences. It can name unmentioned participants or leaks, and later input can disprove each one.

F70
MECHANISM: Every layer is a bijection, and every bit a step would discard goes to an ancilla tape, checkpointed at segment boundaries so it can be recomputed instead of stored. While generating, the model runs backward on each segment from the fixed input and the output so far. The number of ancilla bits it must invent to reconcile them is an exact measure of how much of that output the input does not support. That count is both the training loss and a decoding budget the output must declare and stay within. Removing an example's influence means uncomputing its trace. The count separates grounded content from invented content, but it does not certify that the input itself is true.
VALUE: Lawyers, clinicians and anyone summarizing or answering from sources get an exact count of unsupported bits for every sentence, plus certified deletion of training data. An LLM cannot provide either, because it throws information away at every layer.

F71
MECHANISM: Two unrelated families of probes look for outputs that cannot all be true, for example contradictory answers to logically linked questions. Each such contradiction proves at least one error without anyone grading the answer. The overlap between the errors each family "captures" feeds a Chao estimator, corrected with a log-linear model across a third family, which estimates how many errors remain undetected in each domain. That estimate of unseen error decides where learning effort goes and when the system abstains. First test: Run paraphrase-consistency and negation-consistency probe families (plus an entailment third family) on Llama-3-8B over labeled TriviaQA/BoolQ domains; success means Chao-estimated total errors per domain come within 20% of label-counted errors and rank domains with Spearman > 0.7.
VALUE: It gives the system a quantitative estimate of its own undetected errors, letting it calibrate where to learn and when to abstain.

F72
MECHANISM: Each unit's discretized activation states are treated as alleles over pairs of co-occurring contexts. A heterozygote deficit relative to the Hardy–Weinberg expectation triggers a split into child units. The split is kept only if it satisfies the Wahlund identity on new context pairs: each child must return to Hardy–Weinberg equilibrium (F_IS near 0), and the variance in allele frequency between the children (F_ST) must account numerically for the parent's deficit. This tests the unit against a calibrated null model with known false-positive rates rather than judging the model's own outputs, so a spurious split leaves a deficit inside a child or an unexplained gap, and is merged back.
VALUE: The model breaks apart conflated concepts while it runs, and every split is certified by a statistical identity checked on new data rather than by the model's own opinion of the result.

F73
MECHANISM: For each stored belief, the system runs a cheap twin forward pass with that belief masked out. Whenever a new raw observation arrives (a document token, sensor value, tool output or user reply), it records the difference in prediction error between the full pass and the masked pass. This running per-belief credit is the only quality signal. It sets how strongly each belief is weighted and how much new data may overwrite it. Beliefs with persistently negative credit are retracted, and sources whose added beliefs earn negative credit are down-weighted. First test: Inject 1,000 CounterFact beliefs (half true, half false) as maskable prefixes into Pythia-1B and stream subsequent Wikipedia text; success means accumulated masked-vs-full prediction-error credit separates true from false beliefs with AUROC > 0.75.
VALUE: Every belief is graded continuously by the outside world's next data rather than by the model's own judgment, so learning can stay open-ended in domains with no labels.

F74
MECHANISM: The raw evidence is split into partitions that do not overlap, and a separate copy of the system is trained on each one. The copies answer the same question independently. Agreement counts as a label only when the copies' evidence is disjoint. Its weight shrinks by how correlated their errors are, which is measured by quietly corrupting one partition and seeing whether the other copies follow the corruption. A ledger stores, for each pair of copies, how often they agree by chance and how often their errors move together. Copies whose dissent later turns out justified get more weight.
VALUE: Copies that saw different evidence can label each other's work, and the ledger keeps them from passing shared bias off as truth.

F75
MECHANISM: The network grows its own concepts with a population-genetics test. Each unit's discretized states are treated as alleles over co-occurring context pairs. If a unit shows fewer heterozygotes than Hardy-Weinberg predicts, it is split into child units, and each child gets its own routing and downstream weights. A split is kept only if the Wahlund identity holds on new context pairs: each child must return to equilibrium (F_IS near 0), and the variance in allele frequency between the children (F_ST) must numerically explain the parent's deficit. Otherwise the children are merged back. The test is against a calibrated statistical null with known false-positive rates, not against the model's opinion of its outputs. That makes it a safe way to add capacity during deployment.
VALUE: When a model has merged two things into one concept (two word senses, two patient subpopulations, two failure modes of a machine), it discovers this and grows separate structure for them. Scientists and engineers get each new distinction backed by a statistical guarantee rather than the model's own judgment.

F76
MECHANISM: Four-point-condition violations among concept quartets are computed separately in several distance metrics, each built from independent evidence (text co-occurrence, shared properties, form or etymology, perception). A concept becomes a two-parent reticulation node only when all of the metrics show the violation and each one gives the same admixture weight. A real hybrid is overdetermined: its mixing proportion is one number that every independent geometry must reproduce. An artifact of one embedding breaks tree-additivity in that metric only, and the weight it gives disagrees with the others. Accepted nodes inherit properties from both parents in that proportion, and the weights are re-solved as new evidence arrives, so a node whose weights drift apart across metrics is demoted.
VALUE: The system can represent concepts that blend lineages, such as loanwords, hybrid species and fusion genres, and can tell real hybrids from artifacts of its own embeddings without a labeled oracle.

F77
MECHANISM: The system keeps a growing library of small probabilistic programs, each encoding a candidate causal mechanism (e.g., "pressure causes leak if seal is worn"). When several programs explain the observations equally well, it computes which intervention (real action, simulator query or tool call) would best tell them apart, runs it, and reweights or deletes programs based on the result. New programs are synthesized by recombining fragments of programs that survived, so the library compresses over time.
VALUE: It can discover and reliably use real cause-and-effect structure, including in situations that never appeared in its data.

F78
MECHANISM: The model contains several internal encoders, each trained on a different kind of source (paraphrase, formal translation, tool traces, a separately trained model). Each reasoning step's margins across these encoders are treated as edge flows and decomposed in the forward pass. The gradient part is a per-encoder bias, learned across all steps and subtracted. The curl part is inconsistency, and the step is rejected. The harmonic part is written to memory as a local chart with an explicit context variable, so knowledge is stored as an atlas rather than one flat space. A chart is trusted only if, after fitting on k encoders, it predicts the margin of a held-out encoder before that encoder is scored. Charts whose transition maps keep mispredicting are dissolved.
VALUE: Scientists, lawyers and policy analysts get reasoning that keeps conclusions that hold only in some frames, such as one regime, jurisdiction or theory, and states which frame each one holds in, instead of averaging the frames together or dropping them.
