L01 | PARTIAL | closest work: Coupled Neural Associative Memories, Karbasi/Salavati/Shokrollahi (2013) https://arxiv.org/abs/1301.1555 ; A Non-Binary Associative Memory with Exponential Pattern Retrieval Capacity and Iterative Learning, Salavati/Kumar/Shokrollahi (2013) https://arxiv.org/abs/1302.1156 (also Hopfield Networks is All You Need (2020) https://arxiv.org/abs/2008.02217 and Larimar (2024) https://arxiv.org/abs/2403.11901 as LM-attached memories) | The null-space/sparse-constraint-graph associative memory with iterative message-passing recall and online learning is already published (2013-14); what I found no precedent for is wiring it into a transformer's residual stream (emitting a noisy partial word from hidden states, a straight-through query head, CPU min-sum overlapped with GPU work) as a RAM-resident fact store.
L02 | PARTIAL | closest work: DeltaKV: Residual-Based KV Cache Compression via Long-Range Similarity (2026) https://arxiv.org/abs/2602.08005 ; CacheGen: KV Cache Compression and Streaming for Fast LLM Serving (2023) https://arxiv.org/abs/2310.07240 (also KV Cache Transform Coding, KVTC (2025) https://arxiv.org/abs/2511.01815) | Storing KV entries as residuals against similar earlier tokens and borrowing video-codec delta coding are both published; new is the explicit I/P chunk and GOP structure with per-head motion vectors plus a low-rank residual, a Lagrangian rate-distortion choice scored by attention-output error, and attention that rebuilds P-chunks on the fly (DeltaKV reaches only ~29% of original memory, so the million-token claim is a large extrapolation).
L03 | PARTIAL | closest work: Routing Transformer: Efficient Content-Based Sparse Attention (2020) https://arxiv.org/abs/2003.05997 ; Transformers with Sparse Attention for Granger Causality (2024, time-series, not an LM) https://arxiv.org/abs/2411.13264 (context: Do Long-Range Language Models Actually Use Long-Range Context? (2021) https://arxiv.org/abs/2109.09115) | Local-window attention plus sparse content-selected long-range attention is well known, but I found no work that uses Bonferroni-corrected Granger F-tests on k-means hidden-state clusters and lag bands to create regression-initialized single-query heads and prune them with a Ljung-Box whiteness test.
L04 | PARTIAL | closest work: Low-rank extended Kalman filtering for online learning of neural networks from streaming data, LoFi (2023) https://arxiv.org/abs/2305.19535 ; KOALA++: Efficient Kalman-Based Optimization of Neural Networks with Gradient-Covariance Products (2025) https://arxiv.org/abs/2506.04432 (also K-FAC (2015) https://arxiv.org/abs/1503.05671 and iSAM2 (Kaess 2012) https://people.csail.mit.edu/kaess/pub/Kaess12ijrr.pdf) | Recursive Bayesian/Kalman training that keeps accumulated information, and Kronecker-factored curvature, both exist; I found no work that casts weight blocks as SLAM variables with a sparse square-root information matrix, co-activation-gated cross-block factors, Bayes-tree partial updates and drift-triggered relinearization (likely because such methods have not been shown to scale to LM-size training).
L05 | PARTIAL | closest work: Bilinear representation mitigates reversal curse and enables consistent model editing (2025) https://arxiv.org/abs/2509.21993 ; RotatE: Knowledge Graph Embedding by Relational Rotation in Complex Space (2019) https://arxiv.org/abs/1902.10197 (also relation-aware attention, e.g. RGAT https://pytorch-geometric.readthedocs.io/en/latest/generated/torch_geometric.nn.conv.RGATConv.html) | Bilinear q-R-k scoring, per-relation-type attention and composable rotation operators are known, and RoPE already closes exactly by construction, but I found no precedent for sampling token triangles to measure loop-closure misclosure and using it to split, create (as the product of two operators) and delete relation types in a learned codebook.
L06 | PARTIAL | closest work: CITER: Collaborative Inference for Efficient LLM Decoding with Token-Level Routing (2025) https://arxiv.org/abs/2502.01976 ; R2R: Efficiently Navigating Divergent Reasoning Paths with Small-Large Model Token Routing (2025) https://arxiv.org/abs/2505.21600 (also WhiFlash (2026) https://arxiv.org/abs/2606.07710 for lazy KV catch-up on switching) | Learned token-level small/large routing with a cost-aware reward is already published (R2R reports 1.5B+32B beating R1-7B at 2.8x speedup over 32B) and lazy catch-up prefill appears in WhiFlash; new is the three-tier setup with a forecaster of loss reduction, a subgradient-updated dual price, startup-cost-aware commitment and minimum up-time (the power-systems unit-commitment framing, which I found no LLM precedent for).
NOTE: No idea is a clean KNOWN, but none is clean novelty either: in every case the base ingredient is published (2013 associative memories, delta/codec KV coding, sparse long-range heads, Kalman/K-FAC training, relation-rotation embeddings, small/large token routing), and the claimed novelty lies in the import of an outside-field control or inference machinery (LDPC-style decoding, video RDO, Granger tests, SLAM, surveying, unit commitment) as a scheduling or selection layer around that ingredient. L06 and L02 sit closest to existing systems (CITER/R2R and DeltaKV/CacheGen); L03, L04 and L05 have the least direct precedent but also the weakest evidence that they would work at this scale. Searches were 2-3 per idea, mostly abstract-level, so absence of a hit is weak evidence of novelty rather than proof.
