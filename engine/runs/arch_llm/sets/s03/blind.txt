K01
MECHANISM: A 200M transformer with a 512-token window carries a 32-slot memory from chunk to chunk, kept as 16 perturbed ensemble members that run as batch rows. This is nearly free, because decoding on the RTX 3060 is bandwidth-bound and one read of the weights serves all 16 rows. After each chunk, every member forecasts a summary embedding of it. The actual chunk's embedding is the observation, and a closed-form EnKF update (localized covariance, inflation) moves each member by K(y − Hx). Only the forecast and observation networks are trained, by backprop over short windows. The ensemble spread drives calibration and triggers re-reading, and running it as a smoother lets later evidence revise earlier entity states.
VALUE: It tracks state across long documents while keeping alternative readings alive and reporting its own uncertainty, which a same-budget model with one deterministic state cannot do.

K02
MECHANISM: A 350M transformer runs a full forward pass every step, but backprops only through its top 3 layers, embeddings and readout. This is the cheap fast force. Every k=4 steps it runs one full end-to-end backward pass, and the gradient for the lower layers is applied as a k-scaled impulse, as in RESPA, with momentum split so the average force stays correct. Lower-layer activations from the fast steps need no stored gradients. That cuts both memory and backward FLOPs, to roughly 1.7 compute units per step instead of 3, so about 1.7× more tokens per week fit on 12 GB.
VALUE: On the same card it trains a larger model on more tokens than a transformer that backprops through the whole stack every step.

K03
MECHANISM: The base model is a 256-token-window transformer whose weight blocks are variables in a square-root information matrix in host RAM, updated with iSAM-style Bayes-tree updates. A candidate long-range "wire" (hidden-state cluster × lag band) is treated like a SLAM loop closure. Its innovation on logged surprisal residuals is tested with a chi-square gate using the Schur complement of the current information matrix, which replaces Bonferroni F-tests. Accepted wires join as new variables: their weights come from back-substitution, and cross-block factors are kept only between blocks a wire connects. Whiteness of innovations (Ljung-Box) also triggers relinearization or removal of a wire, so structure and optimizer state are one sparse factor graph handled by the CPU.
VALUE: Long-range structure is added only where it is statistically needed and is fitted from few tokens, giving data-efficient long context that a first-order dense-attention model on 5B tokens cannot reach.

K04
MECHANISM: A 150M backbone sits beside a repertoire in VRAM of up to 8M clones. Each clone is an int8 64-d receptor plus a sparse 4-token logit payload, about 640 MB in total. At positions where surprisal exceeds a running threshold (the danger signal), the layer-8 state acts as the antigen. Clones that bind it compete, and only the one whose payload most lowers that token's loss is "helped". Helped clones divide, and the mutation noise on their receptors shrinks as their affinity rises. Clones that go unhelped for N presentations die, and clones that keep winning freeze as memory cells. Selection uses only forward passes and integer arithmetic, so capacity grows where the data is surprising at almost no FLOP cost.
VALUE: It stores long-tail facts one-shot and adds capacity on demand, far beyond what 150M gradient-fit weights can hold.

K05
MECHANISM: Context is coded in 64-token chunks: keyframe chunks keep fp16 K/V, and the others store a motion vector (reference chunk plus token alignment) and low-rank residual coefficients. Each chunk is a variable in a sparse square-root information graph kept in fp32 in host RAM. The motion-vector references set which cross-chunk factors exist, and reconstruction factors come from attention-output error on probe queries. When a new chunk's key sketch closely matches a distant chunk, a loop-closure factor is added, and an incremental Bayes-tree update on the CPU re-solves only the affected cliques. It re-codes earlier chunks against the new keyframe and pushes corrected residuals to the GPU. The rate controller reads the marginal covariances: uncertain, heavily attended chunks become keyframes or get higher rank, and well-constrained ones shrink to near-zero residuals. The GPU only reads small residuals and does no extra work.
VALUE: Million-token working memory in 12 GB whose compression error falls as more context arrives instead of building up, which neither a truncating transformer nor a one-pass KV codec can do.

K06
MECHANISM: A 200M student scores attention as q·R_c·k over a codebook of 64 orthogonal relation operators, and each step it samples triangles among recent entity tokens and computes loop misclosure. Large misclosure is the dispatch forecast. A dual price λ commits a 4-bit 8B model (paying catch-up prefill and a minimum up-time) only on spans where expected misclosure reduction exceeds λ × cost. On committed spans, the 8B's attention maps between i, j and k are fitted to relation operators. These fits supervise splitting, creating or merging codebook types exactly at the failed loops. As the algebra closes, misclosure and dispatch fall together, so the expensive model ends up teaching only the relations the student cannot yet compose.
VALUE: Near-8B multi-hop relational consistency at small-model cost that keeps falling, because each call to the big model permanently fixes a gap in the student's relation algebra.

K07
MECHANISM: A 256-token-window base model builds, per position, an 8192-bit signature: which of 1024 k-means hidden-state clusters fired in each of 8 log-spaced lag bands. A sparse parity-check graph in host RAM (10-20 GB of edge lists) is learned from training-corpus signatures with a null-space rule, so valid codewords are typical long-range co-occurrence patterns. At inference, 5-10 rounds of min-sum decoding on the CPU complete the partial signature, and a learned projection adds the completed bands into the residual stream. Syndromes that stay unsatisfied are logged. When a check's violations pass a Bonferroni-corrected Granger F-test against surprisal, the system spawns a single-query wire head over exactly those cluster/band positions, initialized from the regression. Wires that later pass a Ljung-Box whiteness test are pruned, and their pattern is folded back into the code as a new check. All decoding and testing is sparse integer or statistical work on the CPU, overlapped with GPU compute.
VALUE: A small windowed model gets long-range structure recalled and error-corrected from corpus-wide constraint memory, plus exact attention only where tests show it reduces surprisal, so its long-range capacity is not capped by VRAM as a same-budget dense transformer's is.

K08
MECHANISM: Each 64-token chunk of KV is hashed to a sparse 8192-bit sketch, and only I-chunks are written as codewords into a constraint graph in host RAM; the rate-distortion encoder (distortion = attention-output error on probe queries) decides which chunks earn codeword status. Motion search becomes CPU min-sum decoding: a new chunk's noisy sketch decodes to the nearest stored I-chunk, which is its reference, so search is sublinear over a million tokens. A P-chunk's residual is stored not as low-rank values but as LDPC syndrome bits of its quantized K/V; at read time the GPU uses the motion-compensated reference as side information and decodes the exact quantized cache from the syndrome. Memory capacity therefore follows attention distortion, and the residual rate shrinks wherever the associative memory supplies a good reference.
VALUE: Million-token code or logs stay exactly addressable even when repeated content has been changed (renamed variables, shifted fields), at a few bits per token that fits in 12 GB plus RAM.
