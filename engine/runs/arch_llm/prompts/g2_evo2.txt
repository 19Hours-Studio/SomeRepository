PAIR 1
 Parent A: MECHANISM: The context is split into 64-token chunks grouped into GOPs. I-chunks keep their full fp16 K/V. Each P-chunk stores, per head, a motion vector (a reference chunk plus token alignment, found by matching key sketches) and a quantized low-rank residual. An encoder chooses between I and P coding and sets the residual rank by Lagrangian rate-distortion optimization, with distortion measured as attention-output error on probe queries. Attention rebuilds P-chunks from their references in shared memory, so the GPU mostly reads small residuals.
   VALUE: Repetitive material such as code, logs and long documents gets million-token working memory in 12 GB, with every token still exactly addressable where a same-budget transformer would have to truncate or evict.
   nearest published work: DeltaKV: Residual-Based KV Cache Compression via Long-Range Similarity (2026) https://arxiv.org/abs/2602.08005 ; CacheGen: KV Cache Compression and Streaming for Fast LLM Serving (2023) https://arxiv.org/abs/2310.07240 (also KV Cache Transform Coding, KVTC (2025) https://arxiv.org/abs/2511.01815)
 Parent B: MECHANISM: Weight blocks (heads, FFN slabs) are treated as SLAM variables. Each batch adds a linearized factor (Kronecker-factored information plus residual) to a sparse square-root information matrix kept in fp32 in host RAM. Cross-block factors are kept only between blocks that are strongly co-activated. A Bayes tree updates only the affected cliques. A block's Jacobians are recomputed on a stored mini-sample only when its estimate drifts past a threshold; otherwise it is solved by cheap back-substitution. The GPU computes forward passes and Jacobian sketches, and the CPU does the sparse Cholesky updates. Each token's information is kept rather than fading out through momentum.
   VALUE: It reaches a target loss on far fewer tokens than first-order training, which matters most when data is the binding limit.
   nearest published work: Low-rank extended Kalman filtering for online learning of neural networks from streaming data, LoFi (2023) https://arxiv.org/abs/2305.19535 ; KOALA++: Efficient Kalman-Based Optimization of Neural Networks with Gradient-Covariance Products (2025) https://arxiv.org/abs/2506.04432 (also K-FAC (2015) https://arxiv.org/abs/1503.05671 and iSAM2 (Kaess 2012) https://people.csail.mit.edu/kaess/pub/Kaess12ijrr.pdf)

PAIR 2
 Parent A: MECHANISM: Facts are stored as sparse binary words (8192 bits, 64 active). Together they form the null space of a large sparse constraint graph held in host RAM (10-20 GB of edge lists), learned incrementally with a Karbasi-style null-space rule over spans the model encodes from the corpus. At chosen layers the model emits a noisy partial word from its hidden state. The CPU runs 5-10 rounds of min-sum decoding to reach the nearest stored codeword, and a learned projection adds that codeword back into the residual stream. The query head is trained with a straight-through estimator. Decoding is sparse integer work on the CPU that overlaps with GPU compute, so capacity grows with code length rather than VRAM.
   VALUE: It recalls whole facts from corrupted or half-given cues, at a capacity well beyond what 200M dense weights hold.
   nearest published work: Coupled Neural Associative Memories, Karbasi/Salavati/Shokrollahi (2013) https://arxiv.org/abs/1301.1555 ; A Non-Binary Associative Memory with Exponential Pattern Retrieval Capacity and Iterative Learning, Salavati/Kumar/Shokrollahi (2013) https://arxiv.org/abs/1302.1156 (also Hopfield Networks is All You Need (2020) https://arxiv.org/abs/2008.02217 and Larimar (2024) https://arxiv.org/abs/2403.11901 as LM-attached memories)
 Parent B: MECHANISM: The base model attends only within a 256-token window, so it is fast and small. Periodically the CPU runs Granger F-tests on logged batches. For each pair of hidden-state cluster (out of 1024 k-means codes) and lag band, it tests whether that cluster appearing in that band explains variance in the current per-token surprisal residual, with Bonferroni correction. Each significant pair creates a "wire": a single-query head that attends only to the positions where that cluster fired inside that lag band, initialized from the regression coefficients. Wires whose Ljung–Box test later comes back white are pruned.
   VALUE: Long-range dependencies use compute only where the data statistically requires them, giving long effective context that a same-budget dense-attention transformer has to truncate.
