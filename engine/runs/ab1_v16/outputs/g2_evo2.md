**Pair 1 (instrument channels × path-multiplicity).** In this fusion, a "route" counts as independent only if it ends in a different instrument lineage. Two derivations that both depend on the same probe's stream count once, however many intermediate facts they avoid sharing. So the multiplicity tally changes which instruments are needed. The trigger for building a new probe is no longer loss that cannot be reduced. It is a conclusion that many routes reach but that rests on only one or two instruments. The system then designs a probe whose stream could re-derive or refute that conclusion by a disjoint path. In the other direction, instruments change primitives. A frozen primitive is stored with the instrument set it rests on. Pruning a channel lowers the multiplicity of the primitives built on it, which can dissolve them. A primitive that survives across ≥3 disjoint instruments is promoted into a virtual input channel.
Closest work: co-training / multi-view learning (Blum & Mitchell 1998), Whewell-style consilience, active feature acquisition, NELL multi-source promotion. None of these designs new sensors to create independent derivations of a label-free conclusion. None ties concept existence to instrument diversity. It differs enough, so no further mutation was needed.

**Pair 2 (commutation carving × commit-reveal).** In this fusion, the module structure carved from commutation sets how fine-grained the commitments are. The system publishes one salted hash per independent thread instead of one per answer. When evidence arrives, the verifier checks two things. First, that each thread's departure is justified. Second, that evidence routed to thread X did not move the commitment of thread Y. Such a shift is either a rationalization or a hidden dependence. The verifier then re-runs swap tests between X and Y. If they fail to commute, the threads are fused and the cross-shift is ruled legitimate. If they do commute, the shift is penalized as post-hoc revision. So belief leakage that commitments reveal changes the independence map, and the map changes what counts as an honest update.
Closest work: Mazurkiewicz traces / Alpha algorithm, causal abstraction with interchange interventions (Geiger et al.), commit-reveal auditing (TensorCommitments). None of these uses externally committed per-module beliefs to detect and repair modular decomposition. It differs enough, so no further mutation was needed.

=== IDEAS ===
IDEA 1
NAME: Consilience-Seeking Instrument Forge
MECHANISM: Background walks count the routes to each conclusion, but routes are independent only if they rest on disjoint instrument lineages. When a conclusion is reached by many routes but relies on few instruments, the system writes and deploys a new probe (code hook, sensor setup, assay, query) designed to give a disjoint derivation path. Primitives are frozen only once they span ≥3 instruments. They store their instrument support and dissolve when a channel they depend on is pruned. Robust primitives are promoted into virtual input channels.
VALUE: Without any external labels, it builds abstractions that are confirmed by independent measurement, and it designs its own instruments to check what it believes.

IDEA 2
NAME: Committed Thread-Locality Ledger
MECHANISM: Swap tests on logged operation sequences split the system into commuting threads. Each thread publishes its own salted hash of its quantized beliefs before evidence arrives. After the reveal, a verifier flags any thread whose beliefs moved on evidence routed to a different thread, then re-runs commutation tests on that pair. If the pair does not commute, the threads are fused and the shift is legitimized. If it does commute, the shift is penalized as rationalization. The module map and the honesty training thus revise each other.
VALUE: Third parties can verify that evidence about one part of the world changed only the beliefs it should have, and the system's modular decomposition becomes auditable and self-correcting.
