All three ideas look only at the text of an answer and how other agents react to it. None of them uses a family list, a forecast, outside evidence, an added verifier, crossover changes, new judges, pairwise matches or a niche archive.

=== IDEAS ===
IDEA 1
NAME: Wording-Stripped Value Floor
MECHANISM: A rewriter agent makes four copies of each survivor that keep the same steps but change the wording: flat bullet points, a hostile skeptic's voice, a 60-word terse version, and a version with every adjective and benefit claim removed. The judges score all four copies blind, and an idea's value is its lowest score across them, not the average. The gap between its highest and lowest score is stored as "rhetoric share." Ideas with a high rhetoric share are sent back to their generator with the stripped copy attached, and a technique's weight in later runs drops as its average rhetoric share rises.
VALUE: Value judgments stop rewarding confident prose, which shared-family judges tend to over-credit. Scores also get less noisy, because only content that survives every wording change counts.

IDEA 2
NAME: Decoy-Question Specificity Margin
MECHANISM: Each survivor is also judged, unchanged, as if it answered 3 decoy questions. A selector agent picks these from other hard open questions to be similar in form but different in substance. Specificity is the idea's value on the real question minus its average value on the decoys, and survivors are ranked by originality times that margin. Ideas with a small margin are labeled "portable generic," and the generator must say which part of the real question its mechanism depends on before it can be kept.
VALUE: It filters out the vague, high-originality answers that score well on any question. That raises the value of the ideas that survive without adding any outside verifier.

IDEA 3
NAME: Peer Uptake Count
MECHANISM: Fresh plain-answer agents, the same kind used in stage 1, are each given the question plus one survivor labeled only as "a colleague's note." They write their own answer and may use the note or ignore it. A judge compares each of these answers with the stage-1 plain answers and records which specific steps from the note were taken up and kept intact. An idea's value is its uptake rate across 5 agents. Its originality must still show that the steps it contributed did not already appear in plain answers written without the note. Ideas that are never taken up go back to their generator with the agents' reasons for ignoring them.
VALUE: Value comes from whether capable peers actually adopt and build on an idea, not from a judge's stated opinion. Because only the steps peers keep count, an idea must stay concrete to earn credit.
