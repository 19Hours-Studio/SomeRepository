Mechanics come first in each idea and the name comes last. I have checked all three against the 13 forbidden families.

1. **Objects:** a grid of oscillating cells, each holding a complex amplitude (magnitude and phase). **Flow:** each candidate partial answer is injected as a wave. Partial answers that contradict each other get opposite phases, so they cancel where they overlap, and consistent ones add up. **Rule:** cells where strong amplitude keeps recurring become stiffer, which cuts permanent channels into the grid. **Signal:** a standing peak that lasts. All candidates are explored at once, and inconsistency is removed by the physics of cancellation, not by checking candidates one at a time.

2. **Objects:** every internal quantity carries a vector of exponents over a set of base "kinds", and this set grows. **Flow:** an operation may only combine quantities whose exponent vectors are compatible. **Rule:** the system repeatedly transforms its own inputs, for example doubling every value of one kind or swapping two kinds. It then checks whether its outputs change exactly as the exponent vectors predict. **Signal:** a failure under this test either splits a kind into two new kinds or changes an exponent. The result is extrapolation to magnitudes it has never seen, plus a built-in sanity check.

3. **Objects:** a store of short, articulated lessons, and a small empty "student" with limited capacity. **Flow:** from time to time the system rebuilds the student from nothing, using only the lessons, and tests it on held-out cases. **Rule:** a lesson that is linked to the student's failures gets rewritten, split or expanded. A lesson whose removal does not change the student's score gets deleted. **Signal:** the transfer gap, meaning the system's own accuracy minus the student's. Knowledge is valid only if it can be passed on, so unspoken pattern-matching gets exposed and turned into explicit statements.

=== IDEAS ===
IDEA 1
NAME: Interference-Carved Resonance Grid
MECHANISM: Candidate partial answers are injected as phase-coded waves into a grid of oscillating cells. Contradictory candidates get opposite phase and cancel, while mutually consistent ones reinforce into standing peaks. Cells that repeatedly hold strong amplitude stiffen, cutting lasting channels that bias future propagation. The stable peak pattern is read out as the answer.
VALUE: Many alternatives can be searched at the same time, with inconsistency removed physically rather than candidate by candidate.

IDEA 2
NAME: Rescaling-Tested Kind Exponents
MECHANISM: Every internal quantity carries an exponent vector over a growing set of base kinds, and operations may only combine compatible vectors. The system keeps rescaling or swapping kinds in its own inputs and checks that its outputs change exactly as the exponents predict. Each failure splits a kind, adds a new one, or revises an exponent.
VALUE: Reliable extrapolation far beyond the magnitudes in its experience, plus automatic detection of answers that make no sense.

IDEA 3
NAME: Teach-Back Transfer Gap
MECHANISM: Knowledge is also held as short, explicit lessons. Periodically a small, empty student is rebuilt using only those lessons and scored on held-out cases. Lessons linked to the student's failures are rewritten or split, and lessons whose removal leaves the score unchanged are deleted. The size of the gap between the system's accuracy and the student's drives the rewriting.
VALUE: Unspoken, unexplainable competence becomes explicit, checkable knowledge that can be passed on, so the system knows which of its skills it actually understands.
