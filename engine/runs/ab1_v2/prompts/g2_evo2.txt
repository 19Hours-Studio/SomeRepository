 Parent A: MECHANISM: Closes G2. For each real task type, the system builds twin tasks in the easy direction, where the answer is fixed first and the problem is generated from it: run a program and then ask for its output, hide a known span and then ask to reconstruct it, compose a plan and then ask what goal it achieves. A discriminator is trained adversarially until it cannot tell the twins from real tasks. The system stores per-twin-cluster accuracy for every checker and solver. On a real task with no oracle, the correctness estimate is the measured accuracy on the twins that match it most closely.
   VALUE: It gives a calibrated, always-available correctness signal on tasks where no verified outcome will ever arrive.

PAIR 2
 Parent A: MECHANISM: Closes G1. The system does not parse the input directly. It applies a large set of small edits to the raw input (swapping a token or phrase, inpainting an image patch, shifting time) and records how each edit changes a frozen predictor's output distribution. Edits are clustered by their effect signature, and each cluster becomes one variable whose values are the observed edit outcomes. A typed link is added wherever a pair of clusters shows a non-additive second-order effect, meaning editing both does not equal the sum of editing each. The edit library and clusters are stored, and the clustering is refit as new inputs come in, so the structured form is built from the input itself rather than hand-specified.
   VALUE: It turns "parse the input into the representation" into a measurable procedure that works the same way on text, pixels and sensor streams.
   nearest published work: Automated Discovery of Pairwise Interactions from Unstructured Data (2024) https://arxiv.org/pdf/2409.07594 ; Discovering unexpected local nonlinear interactions in scientific black-box models (Hint, KDD 2019) https://cris.huji.ac.il/en/publications/discovering-unexpected-local-nonlinear-interactions-in-scientific/
 Parent B: MECHANISM: A candidate inference step must survive K sequential, irreversible holding stages before it is committed. At each stage it is re-tested for match against an independently perturbed context, and if it detaches it resets to the beginning rather than to the previous stage. Errors therefore decay roughly as f^K. The number of stages a candidate survives gives a confidence score, and the system can raise K wherever stakes are high.
   VALUE: Reasoning accuracy can be bought with compute in a predictable, near-exponential way, instead of being capped by a single forward pass.
