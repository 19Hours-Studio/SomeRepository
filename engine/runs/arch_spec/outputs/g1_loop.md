Diagnostic loops (short form):

1. Power-grid state estimation. The largest-normalized-residual test, which also catches topology errors. Ported to stratigraphic relation graphs. The flagged edge is deleted or reversed, or the context is re-typed as a "cut". Closest existing work: the cycle checks in Harris-matrix tools (Stratify, ArchEd) and OxCal outlier models. Those only flag cycles or date outliers. They don't find the single bad relation and re-type it.
2. Population genetics. Linkage disequilibrium and the Wahlund effect, which expose hidden mixed populations. Ported to tool-mark clusters. A significant LD score splits a prototype, or re-types it as a resharpening successor. Closest existing work: G-means, which splits clusters on a Gaussianity test. That has no discrete-locus independence test and no temporal re-typing.
3. Crystallography. The Fo−Fc difference map with R-free validation. Ported to drainage maps. Peaks above 3σ insert drain segments and troughs below −3σ delete them, and an edit is kept only if held-out R-free improves. Closest existing work: ARP/wARP auto-building in crystallography itself, and greedy matching pursuit. Neither builds graph-structured, flow-coupled networks from field imagery.

=== IDEAS ===
IDEA 1
NAME: Residual-Tested Stratigraphy Builder
MECHANISM: The task is building an archaeological Harris matrix, the ordering of soil layers, from trench photos, level readings and excavators' notes. AI has been absent because each site is unique, labels are tiny and errors are buried in hand-drawn sheets. A 30M-parameter segmentation-plus-relation network turns photos and notes into a graph: nodes are contexts typed deposit, cut or fill, and edges are above/below relations with confidences. A weighted least-squares "state estimator" fits a latent depth-time coordinate to each node from every redundant relation and elevation. The largest normalized residual (power-grid test) names the single worst relation, which is then deleted, reversed, or used to re-type its node. Training is self-supervised from internal consistency on about 200 published matrices plus synthetic layer-cake simulations, and the solver is sparse, so all of this runs in seconds on the 3060.
VALUE: It finds and fixes the one wrong relation or mis-typed layer behind a contradiction, not just reporting that a cycle exists.

IDEA 2
NAME: Linkage-Split Axe Signatures
MECHANISM: The task is attributing hand-hewn timber in historic buildings to individual axes and carpenters from phone photos of tool marks. AI has been absent because there are no labels, marks are worn, and it is a craft-history niche. A small CNN (about 15M parameters) turns each mark into binary "nick loci", the presence of blade-edge defects at positions along the edge, and these are clustered into blade prototypes stored in RAM. Within each prototype, pairwise linkage disequilibrium between loci is measured. One blade should give independent noise, so significant LD means two blades were mixed together. A split tested by mutual information then creates two prototypes. If the LD pattern is nested (one nick set is a subset of the other), the split is re-typed as a resharpening successor edge in a time-ordered blade lineage. The encoder trains contrastively on augmented crops, with re-clustering after each split.
VALUE: It recovers how many tools were used, their sequence, and the build phases of an undocumented structure from cheap photos.

IDEA 3
NAME: Difference-Map Field Drain Recovery
MECHANISM: The task is mapping lost 19th-century clay field drains under farmland from drone RGB and thermal images taken after rain. AI has been absent because no ground truth exists and the drains are invisible, so only slow GPR surveys have been used. A 20M-parameter U-Net predicts surface wetness from a current drain graph, using a fast non-differentiable Darcy flow solve on a 512² grid, and observed minus predicted gives the difference map. Ridges above 3σ insert drain segments by tracing along the ridge, troughs below −3σ delete segments, and each edit is kept only if R-free, the error on 5% of held-out pixels, improves. The U-Net is pretrained on simulated fields with random drain layouts, then fine-tuned self-consistently on real flights. Everything fits easily in 12 GB.
VALUE: It turns one post-rain drone flight into a validated drain network with honest error bars, which a pixel segmenter cannot do without labels.
