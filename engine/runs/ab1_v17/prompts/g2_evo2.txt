PAIR 1
 Parent A: MECHANISM: Every quantitative or relational claim the system holds is treated as a surveyed observation with a variance, and it is linked to independent observations (retrieved sources, tool outputs, sensor readings) through closed constraint loops. Weighted least-squares adjustment spreads each loop's misclosure across its claims. Baarda's normalized-residual test then names the specific claim that is most likely a blunder, which gets revised or discarded. For each claim the system stores a redundancy number that says how far other observations control it. Claims with near-zero redundancy are marked as structurally unverifiable rather than as trusted.
   VALUE: The system can locate and fix its own errors, and knows which beliefs nothing can currently check, without an oracle or a self-grading model.
   nearest published work: Baarda data snooping and reliability/redundancy theory in geodetic least-squares adjustment (1968/1977; review "A half century of Baarda's concept of reliability" https://agrimensura.florianopolis.ifsc.edu.br/wp-content/uploads/2026/07/A-half-century-of-Baarda-s-concept-of-reliability-a-review-new-perspectives-and-applications.pdf) ; ConCoRD: Enhancing Self-Consistency and Performance of Pre-Trained Language Models through Natural Language Inference (2022) https://arxiv.org/abs/2211.11875 (also Belief Tree Propagation (2025) https://arxiv.org/html/2406.06950v2)
 Parent B: MECHANISM: The system injects graded perturbations into live tasks, and the correct effect of each one is known by construction: inserted facts with fixed consequences, unit rescalings, swapped entities, planted sub-results. It fits a line of output shift against spike size. The slope gives recovery for that input type, and extrapolating the line to zero spike gives a bias-corrected answer. Input types with low or uneven recovery get their own adapter modules, and an adapter is deleted if recovery does not improve. The system only grades known differences, never its own absolute answers.
   VALUE: Context-specific distortions are measured and corrected on real inputs where no answer key exists.
   nearest published work: Standard addition method (analytical chemistry, long-established; spike known amounts, regress response, extrapolate to zero) https://en.wikipedia.org/wiki/Standard_addition ; LLMORPH: Automated Metamorphic Testing of Large Language Models (2026) https://arxiv.org/abs/2603.23611 (also Yee et al. error-injection recovery tests on chain of thought, found via search but not opened)

PAIR 2
 Parent A: MECHANISM: The model's beliefs act as a background state. Each new datum from a document, user, instrument or tool is an observation, and the system computes the innovation (observation minus prediction) and the analysis residual. Desroziers consistency identities over these statistics give separate estimates of the model's error covariance and of each source's error covariance, so no labels are needed. These estimates set the gain that decides how much each observation changes the stored beliefs and parameters. A source whose estimated error grows is down-weighted automatically, and so is a model region whose estimated error grows.
   VALUE: The system learns continuously from noisy, adversarial real-world streams while measuring its own reliability and each source's reliability from the data alone.
   nearest published work: Desroziers et al., Diagnosis of observation, background and analysis error statistics in observation space (2005) https://bibliotheque.meteo.fr/pub/DOC00017306-diagnosis-observation-background-and-analysis-erro.html ; Knowledge-Based Trust: Estimating the Trustworthiness of Web Sources (2015) https://arxiv.org/pdf/1502.03519 (Kalman-style LLM work: Filtering Beats Fine-Tuning: A Bayesian Kalman View of In-Context Learning (2026) https://arxiv.org/abs/2601.06100v1)
 Parent B: MECHANISM: Each claim or explanation the system produces is given to a small, freshly initialized student model. The claim is scored by how much it improves the student's prediction of held-out raw observations from the domain, compared with a student that did not receive it. The system stores these gains per claim and trains itself toward claims with high gains, while claims with no gain are demoted.
   VALUE: It grounds correctness in abundant unlabeled data, which exists everywhere, instead of in the system's own fallible judgment.
